## 怎么填写

- 优先填 **A 组**，它决定下一项可玩功能。其余按组填写即可，不必一次答完。
- 每项可填选项、自定义方案、`按推荐`、`交给你设计`或`暂缓`。`交给你设计`表示授权我在该项边界内提出并试验方案，记录为委托设计，不伪装成你逐个确认了数值。
- 可以直接在聊天中回复 `A01=……，A02=……`，也可以改本文各表的“你的答案”栏。具体单位数值可整批委托，不要求你先当数值策划。
- 空白不是同意。未回答只推迟依赖该决定的功能，修复、验证等独立工作仍可进行。改变核心玩法或超出委托边界时会明确指出影响。
- 收到答复后，先同步已定规则，再只实现下一项闭环并提交 Git；不是把下列所有大系统一次性开工。

## 不需要重复回答的已定事项

Windows 离线单机、键鼠、Unity 6000.6.5f1；视角为类似《明日方舟》的正向斜俯视 2.5D，横边水平，地图必须接近其战术环境风格、铺满背景，上方防御、下方角色栏。角色延续认可的有趣像素感风格，向右常态保留原三分之四正面。
