# 九羁绊独立试玩与配置说明

2026-11-06。代码入口、配置类型及编辑器生成工具已接入；**新场景生成、Unity编译、PlayMode、自然触发和独立EXE验收仍待主任务执行**。下文写的是当前配置与操作目标，不把未跑的自然战斗当作已通过。实际结果以后续 `QA.md` 为准。

## 从哪里进入

游戏内打开右上角“菜单”→“返回测试选择”，在角色测试页选择“九羁绊专项 · 独立场景”，再选目标羁绊。旧“羁绊验证 · 无限金币”综合入口继续保留。

Unity中，生成后可在 `Assets/Scenes/SynergyTrials/` 双击目标 `.unity`，直接看到和编辑已保存的地图。不是进入Play后才生成地形。各专项复制现有综合验证地图的真实GameObject，保留相同地形、门、路线和装置，分别配置初始卡组与守军。

若新场景尚未生成，先由主任务在保存并关闭人工编辑后执行：

- `YesterdayConvoy.Editor.SynergyTrialSceneTools.CreateMissingScenes`
- 菜单位置：`Yesterday Convoy → Synergy Trials → Create Missing Authored Scenes`

工具只补缺失Scene和配置，不覆盖已有地图或Inspector修改；新Scene拥有独立GUID。之后用同菜单 `Validate Authored Scenes` 校验，再做Unity运行验收。不要运行旧地图生成工具。

## 一次试玩怎么操作

1. 进入后先看左侧人数、档位，点击羁绊查看具体效果。构筑面板可选感染形态、海嗣适应、承契角色和巨像培养预置。
2. 整备中可以无限刷新、购买、出售、升星、升级和改编队。上方是商店，下方是编队/备战平台；把卡拖到两侧出售。
3. 点“开始下一战”，再把卡拖到红门。暂停时也能拖动部署并立即扣DP，但移动、攻击、SP和CD继续暂停。普通拖动结束后要重新抓卡。
4. 看清某一机制后，可以用“结束验证，返回整备”继续改组，或经正常胜负结算返回整备。中途返回不发胜利培养。
5. 要重测相同开局，可在菜单重开；要保留当前运营只重打战斗，用“重开本关（保留运营）”。

无限金币只绕过金币不足，**不提供无限牌、无限DP或无限部署**。42种卡共用原卡池，每种仅9张基础牌；1/2/3星分别占1/3/9张，商店展示也占库存，刷新未买商品才返库。已经持有三星后刷不出该角色是正常库存结果。部署次数、CD、技力及触发条件都保留。

## 在Inspector里怎么改

| 想改什么 | 文件/位置 | 字段 |
|---|---|---|
| 开局成员、星级、等级 | `Assets/Data/SynergyTrials/<稳定ID>.asset` | `initialMembers`里的 `cardId/star`、`initialLevel` |
| 初始感染/海嗣形态 | 同上 | `infectionPrimary/Secondary`、`marinePrimary/Secondary` |
| 初始承契角色 | 同上 | `contractCardId`，必须属于初始成员；空值取首人 |
| 守军数值、站位、阻挡和技能 | `Assets/Data/SynergyTrials/Encounters/<稳定ID>-defenders.asset` | `defenders`各项 |
| 场景绑定哪套开局 | 打开目标Scene，选择 `CampaignBootstrap` | `trialDefinition` |
| 地图地块、装置、灯光 | 目标Scene的Hierarchy | 修改后保存该Scene |

稳定ID用于查表，不要把它改成显示标题。初始表代表出战编队，因此同名只能一张，星级必须1–3，人数不能超过初始等级；需要多张升星材料应在游戏整备中购买并放备战席。每场景有独立守军资产，修改某专项不会改综合验证或其他八个专项。

守军资产保存的是**倍率前基准值**。默认专项沿用怪物生命×4、攻击/技能×2，守军生命×12、攻击×8；DP100。重开会重新拷贝基准，不应再次累计乘12。不要把期望实机HP直接填为基准后忘记倍率。

|---|---|---:|---:|
| 整合 | 4地面 | 200→2400 | 8→64 |
| 雪怪 | 6个近邻地面目标 | 400→4800 | 6→48 |
| 感染 | 4地面，能自然击杀小怪 | 120→1440 | 18→144 |
| 游击 | 4地面，留时间积军令 | 250→3000 | 10→80 |
| 泥岩 | 4地面 | 200→2400 | 12→96 |
| 牧群 | 4地面，能自然击杀宿主 | 100→1200 | 20→160 |
| 深池 | 6个近邻地面目标 | 100→1200 | 10→80 |
| 海嗣 | 2地面+2高台克洛丝 | 地面100→1200，高台70→840 | 10→80 |
| 萨卡兹 | 4耐打地面目标 | 350→4200 | 16→128 |

这些是**待实机校准的试验值**，不是最终平衡结论。自然触发不顺畅时，优先调整该专项守军基准，并记录原因；不能强设死亡、火种或培养后称为自然验收通过。

## 九项观察步骤

### 1. 整合运动：部署触发援军

依次部署至少3种不同卡，观察士兵、弩手援军出现；它们不扣DP、不消耗卡牌次数，穿蓝门不扣防御。6档每场最多3次。再在整备中改成4人或2人，比较援军类型、数量与次数。死亡或尚未部署不应改变本场固定档位。

### 2. 雪怪小队：冻结、碎冰与霜星冰封

先放雪怪狙击手/术师，再放冰爆源石虫或霜星，让同一被冻结目标在2.5秒内被不同种类命中，观察碎冰计数与群体效果。霜星满SP后手动冰封，观察8秒暴风雪在0/2/4/6秒施加寒冷。移出霜星后应降到2档，不存在旧4档。

默认五成员含全部雪怪。目标群较耐打是为了留出冻结与多次命中的时间；不要用一个即死目标判断群体技能是否有效。

### 3. 感染生物：固有爆炸与羁绊爆裂

默认主爆裂、副甲壳。先只放一只普通源石虫，让守军正常击杀，观察额外爆裂；再放高能源石虫、冰爆源石虫，检查固有爆炸与羁绊爆裂各结算一次，没有覆盖或递归爆炸。切换集群/甲壳再看分体和护盾；副形态只按2档。

先少量部署。一次把整队围上去可能让守军先死，无法看到怪物自然死亡反馈。

### 4. 游击队：军令与半令

让不同卡实际攻击或受击，观察军令上升，每种卡最多2点。6档满6点用整令，或用两次3点半令；同一轮半令参与者不能重复。暂停、无目标或动作未完成时不能空扣。改2/4人后比较成本、次数和目标数。

### 5. 泥岩小队：培养不是开局赠送

默认5名成员全1星，**培养0、投入0、巨像I**。5档只是终极资格，并不会直接送IV。先部署胚体看单场一次与DP，再通过真实胜利/投入或明确的验证预置比较成长。

| 巨像 | 培养 | 累计投入 | 队伍条件 |
|---|---:|---:|---|
| I | 0 | 0 | 2名成员即可部署 |
| II | 4 | 20 | 2名成员 |
| III | 12 | 45 | 4名成员 |
| IV | 24 | 80 | 5名全部至少二星 |

正式胜利且两种小队成员实际交战+3培养，4档且巨像也交战再+1；补给不培养，每个关间最多投入10金币。无限金币不绕过上限。专项不是完整运营挑战，快速测II–IV用原有显式预置，并注明它是测试设置。

IV原数值基准沿用完整六星防线并关闭试验倍率，不能与默认倍率试验混为一谈。五名二星各占3张基础牌，仍符合九张库存。

### 6. 牧群：正常死亡后的转化

先仅部署宿主士兵，让其受到守军攻击直至最终死亡，观察转化体延迟出现、剩余时间和沿原路线继续移动。4档最多前5个非五费正常实体转化；梅菲斯特自身不转化。转化体不能继续转化，不复制主动/爆炸/羁绊资源，穿门不扣防御。

先看单只再加队友，避免守军被秒杀。原死亡动作和转化体可能短暂同屏，需结合计数判断。

### 7. 深池：灼燃后正常击杀产生火种

先让焚毁者喷火积灼燃，再补方阵/逐火战士等正常伤害击杀，观察火种和邻近传播。留活目标，攒到2枚后引爆，检查扣2枚、同场最多2次；没有合法目标不能空扣。

灼燃累计阈值100，喷火逐次积累；目标太脆会在灼燃前死而不产火种。当前生命只是校准起点，必须验证完整“灼燃→正常击杀→传播/引爆”，不能把测试脚本塞火种当作通过。

### 8. 海嗣：三种适应与胜利成长

分别选择屏障/猎食/渗透。屏障要受到高台克洛丝真实远程命中；猎食等目标低于35%生命；渗透看首次命中降甲、同名不无限叠。

初始培养0、成长I。I/II/III需要XP0/3/7；真实接敌的每种成员胜利+1，4档每胜最多3，因此完整接敌至少1胜到II、3胜到III。4海嗣到II才有I阶段副适应。只部署、未接敌或中途返回整备都不送培养。

### 9. 萨卡兹：受伤承契与爆发

默认承契者M37萨卡兹大剑手。先让其他种类友军正常受击跨40%生命线，每种最多2点；攒4点后选存活M37施放承契。观察攻击、护盾、持续时间及6档友军护盾。

承契者自己、支援、分体和转化体不产点；暂停或没有活承契者不能空扣。不要先把承契者送死，也不要只用一种卡期待攒满4点。开战前可在构筑面板更换承契者。

## 塔露拉完整双阶段独立场景

角色测试页另有“三星塔露拉 · 完整双阶段”；Unity场景为 `Assets/Scenes/TalulahPhaseTrial.unity`，使用已保存MonsterTrial地形，进入后直接试玩，无需再次选角色。

场景的 `TalulahPhaseTrialBootstrap` 可在Inspector修改初始DP/守方防御、A阶段生命/攻击/护甲，以及 `encounter` 引用。守军资产为 `Assets/Data/Trials/TalulahPhaseDefenders.asset`，可改三名克洛丝的生命、攻击、间隔、护甲、射程与站位。

默认A阶段4250生命/336攻击/12甲；三星运行快照开启双阶段，B由领域乘1.5得到6375生命/504攻击。3名高台克洛丝各50000生命、140物攻、40甲、1秒间隔、0阻挡，射程9覆盖交战点。本场只部署一次，拖到红门即可；保留SP和手动火雨，让守军真实射击推动首倒、首轮自动火雨、B形态、终倒、最终火雨和最终死亡。

该专项不修改普通一二星或共享配置的双阶段开关。不要用大伤害注入代替自然承伤，也不要把B的1.5倍再手工乘一次。生成方法是 `YesterdayConvoy.Editor.TalulahPhaseTrialTools.CreateMissingScene`，当前Unity自然阶段/动作/特效验收待主任务执行。
