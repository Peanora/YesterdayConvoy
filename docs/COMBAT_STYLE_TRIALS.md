# 六打法羁绊与专项试玩

2026-11-10，人类确认按本次六条初稿接入。以下为获准接入的试玩初值，尚未经过长期平衡验收；实现、测试和构建事实分别见 STATUS / QA。

## 进入试玩

直接打开 `Builds/Windows/YesterdayConvoy.exe`。右上菜单选择“返回测试选择”，点击“阵营 / 打法羁绊试玩 · 独立场景”，切换“打法羁绊 · 六条”，选择对应专项。

六个专项均为独立保存的 Unity 场景，编辑模式可见地形。每场初始8级、100DP、八张一星编队卡，无限金币，仍使用真实的分费用库存、购买、合成、编队格、部署次数/CD和SP。可以正常刷新、升星或更换编队；战斗结束可回整备继续试验。无启动脚本，无ZIP或Releases。

专项沿用既有观察倍率：普通卡生命×4、基础攻击/治疗/SkillAttack预算×2，守军生命×12、攻击×8；不修改源资产。护甲、动作时序、速度、SP、CD和部署规则不因该倍率改变。该测试配置不代表正式行动的强度。强攻专项两路各配置一名近门拦截的高甲守军，建立真实阻挡条件，没有扩大通用阻挡半径或改动正式地图。

正式行动、综合羁绊验证和六打法专项同时启用阵营与打法。原九个阵营专项保持阵营单独验证，以便复现原机制。角色单怪测试不增加编队羁绊。

## 通用规则

- 初版42种可招募角色各有一个打法标签；原阵营标签保留。银狼后续制作仍暂缓，不为填打法而解锁。
- 人数按战前编队不同种类锁定，只取最高档。备战、重复部署、死亡、穿门和跨波不改变档位。
- 分体、援军、巨像、灵体不计人数，也不独立触发或领取新增效果；派生伤害不递归触发。原生攻击已持有的预算按原有继承规则处理，不重复加算。
- 时长和资源使用共享模拟时钟，暂停冻结。跨波保留状态/贡献记录；新战斗和重开清空。新正常部署实体具有自己的壁垒/狂袭资格，原实体复起不刷新。
- 不额外乘总星倍率，相关效果读取实体实际攻击或最大生命；狂袭攻击与整合、萨卡兹、传令等同类加法项合并。

## 机制

| 打法 | 2档 | 4档 | 6档 | 触发与对象 |
| --- | --- | --- | --- | --- |
| 强攻 | 忽略20%正护甲 | 35% | 50% | 成员普攻有效命中正在阻挡普通友军的守军，施加4秒破阵。全队普通实体对该目标的直接物理伤害获益，首击不追溯加成。先原有减甲，再计算忽略；负护甲不被拉高。 |
| 射手 | 远程直接伤害＋6% | ＋12% | ＋18% | 两种不同射手卡在2.5秒内直接命中同一守军，暴露4秒。全队普通实体按原战斗配置的远程身份获益；同种多实体不能独立完成双来源条件。 |
| 秘术 | 40%攻击力法伤 | 70% | 100% | 每实体每3次有效普通攻击触发一次脉冲，目标及1格内最近另外2人。每次完整普攻只计一次，多段/多目标不多计；脉冲派生，不产其他羁绊资源。 |
| 壁垒 | 8%生命盾，额外保护1人 | 14%，1人 | 20%，2人 | 成员首次承受守军有效直接攻击且存活，给自己及1.5格内最近普通友军各自最大生命比例护盾，持续5秒。同名取高刷新。沿现有普通盾规则，真实伤害穿透；致命首击不救场。 |
| 狂袭 | 攻击＋15%，吸血8% | ＋25%，12% | ＋35%，16% | 成员首次降至半血或以下且存活，狂热8秒。仅普通攻击的主目标实际生命损失可吸血，每次完整攻击合计最多回自身最大生命5%；多段共用上限，副目标、债务与DOT不吸血。原生自损可启动狂热。 |
| 协同 | 每次回复5 SP | 每次8 SP | 无 | 每种成员首次有效直接命中或有效治疗贡献一次记录；每两种消费记录，给当前在场、未复起/转阶段、有SP技能的普通实体回复。每种本场只能贡献一次，2档最多1次、4档最多2次；溢出不储存，不重置弹药、技能动作或其他CD。 |

“有效命中”以实际生命损失或生命债务增加为准。治疗要求实际恢复生命；纯摆放、满血空疗、自疗/持续回复和派生伤害不贡献协同来源。狂袭的5%上限约束新增吸血，角色原生吸血能力保留。

强攻严格要求真实阻挡；普通近战在自身射程内停步，不能把“正在交战”冒充“已被阻挡”。正式地图需利用实际接阻挡的实体/部署条件配合。焚毁者喷火、蔓德拉凝视等原生技能不当作多次普攻；其正常普攻仍按原有攻击路径参与对应打法。

## 每条怎样观察

先点左侧羁绊打开详情，核对全部成员、当前编队和唯一生效档；查看后关闭，再拖动底部卡到红门。

| 专项 | 建议操作 | 真实反馈 |
| --- | --- | --- |
| 强攻 | 先让大剑手等近战接敌，守军挡住它后观察后续物理攻击 | 目标“破阵”状态、实际掉血，侧栏破阵目标数 |
| 射手 | 同一路线部署弩手与雪怪狙击手 | 两种卡命中后出现“暴露”，侧栏暴露目标数 |
| 秘术 | 先重装防御者，再术师；让其完成三轮普攻 | “秘术脉冲”提示及附近守军真实伤害，侧栏累计次数 |
| 壁垒 | 先士兵，随后弩手，保持接敌时彼此距离接近 | “壁垒掩护”、独立青色护盾条、实际吸收跳字及侧栏次数 |
| 狂袭 | 先出猎狗，让它真实承伤到半血 | “狂热”、攻击变化与实际绿色治疗跳字，侧栏累计次数 |
| 协同 | 先部署维维美/霜星并使用技能，再让酸液虫、传令兵接敌；后续可用宿主士兵、梅菲斯特有效治疗完成第二组 | “协同接续”、实际“＋N SP”，侧栏累计接续次数和SP总量 |

准备阶段可移出成员，分别核对2/4/6档（协同2/4），也可混搭阵营和打法。五费并非所有低档的必要条件；6射手需要维维美，6秘术需要至少两名五费，属于后期专精目标。

## 代码连接与验证入口

`CombatStyleRules`持有成员、档位、系数和共用文案；`ConfigureSynergies`可选开启打法并锁定快照，正式控制器明确开启。`CombatStyleSynergies`处理直接命中、原生治疗、普通攻击组、受击、生命变化和盾池。每个普通攻击包保存创建时的动作编号及主目标；延迟、多段和群攻使用同一个动作资格，避免读到后来一次攻击的计数。

`CombatFeedback`只投影真实状态、伤害、治疗、盾吸收和SP到账；`SynergySidebar`/详情显示真实档位、成员和触发记录。打法徽章复用已有边框和字体，使用“强/射/秘/壁/狂/协”字标，无新增角色美术或外部资源。

`SynergyTrialCatalog.StyleEntries`登记六个专项；`SynergyTrialSceneTools.CreateMissingScenes`只创建缺失资产/场景，已保存地图与Inspector值不覆盖。六张场景位于`Assets/Scenes/SynergyTrials/*StyleTrial.unity`，各有独立配置和守军资产。

开发验证：EditMode `CombatStyleTests`；非batch D3D11 PlayMode `CombatStyleSceneTests`。可选Player命令行`-combatStylesSmokeTest -demoEvidenceDir <输出目录>`调用真实指针与技能接口遍历六场，输出真实检查结果；追加`-combatStylesScreens`才要求完整屏幕截图检查。这是程序化生产接口验证，不是人工鼠标操作、自然抽卡运营或平衡胜率。
