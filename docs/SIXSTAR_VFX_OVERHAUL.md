## 源素材和显示

- 新四位正背共八套原身体动作，新增旧 D23/D24/D26 已核实的选中分支；不通过整体平移或弹跳冒充原动作。角色待机可见高度采用现有游戏的 1.25 单位合同，保留逐段独立 PPU 和脚点。
- 既有原 PNG 中的 HDR 编码 RGBA 无损恢复为运行页；新采样使用原 prefab、材质和真实的必要轨迹或端点输入。`SixStarVfx/` 资源限定为有界 RGBA32 线性上传，保留 alpha=0 的加色 RGB，避免压缩和透明清边吞掉光效。
- 专用 `SixStarNative` 还原线性 HDR，在 Gamma 输出仅进行一次显示转换。原作拍摄已经包含的地面透视保留于图像，使用真实地面深度而不重复压扁；角色附着层使用脚点立面深度。已有非六星素材继续原路径。
- 常驻效果按每段源序列测得的稳态窗口重复；起手只播放一次。不是把每次攻击、亮度归零的冷启动或伤害计时当成常驻循环。
- 地面标记和身体/弹道分层。保持真实遮挡，不使用全局无条件穿透，也不把全部攻击特效一律塞到角色后方。
- 已核实的武器层使用原骨骼逐帧轨迹，内联于对应身体 manifest；通过当前实际 sprite 的正背、片段、帧号和翻转取点，不另乘一次原父层缩放。原 IL2CPP 元数据确认挂点编号在 6 与 8 之间插有 Ground=7，不能按连续编号猜特殊骨点。只对白名单中有原 FollowMountPoint 证据的层应用骨锚。

## 真实事件连接

模型 → 不可变攻击快照/真实呈现日志 → `DefenderSkillVfxView` → 原特效分层池；身体由 `DefenderRosterView` 消费同一次真实动作和发射时点。

`CombatShot` 保存动作开始时刻、动作速率和当时技能状态；预发射的起手、发射、目标到达各自计时。后续攻速、技能结束或另一动作不会改写已经发生的攻击。D24 空投仅消费真实增援成功事件；D23 自疗消费真实回复记录；D27 雪格从实际出生时刻播放，雪地命中仍只消费已成功结算的只读接触。

新四位的粘液、起飞移动、侵蚀爆发、医疗释放和落地均由模型真实事件驱动。范围追加结算使用独立标记，避免每个受击者都重复生成一遍施法者和弹道；显示层不扣血、不治疗、不追加攻击。D24 S3 默认起手按源动作由 0.7 秒改为 1.6 秒，原弹药和伤害量保留。

原源引用优先于文件名推断。例如 D34 的 range 是技能全程施法者被动层，而 Mark_all 属于真实侵蚀爆发；D35 的子弹道中 indicator_heal 与伤害分支确有原交叉引用，不能凭名称互换。方向分支按原面向触发，不以角色站高台作为 Down 条件。

## 来源与适配边界

原始资源来自本轮已核实的官方版本 `26-10-29-15-36-11-33649006` 及既有原生采样缓存；每个已接入身体目录保留来源清单、SHA 与权利说明，特效中央清单旁保留 `sixstar-source-audit.json`、`sixstar-emitter-audit.json` 和 `sixstar-new-emitter-audit.json`。原作媒体权利属于原权利人；用户接入/上传决定不记为开放再分发许可。

本作使用固定镜头、身体序列和原粒子采样重放，不等同完整原客户端。稳态窗口不代表已证明原循环数学无缝；部分原挂点、生成器和动态投影由当前角色/目标位置适配。精确限制和本轮实际验证结果写入 QA，未运行项目不冒称通过。

本轮明确保留的缺口：D26 的原武器 Trail 在已核骨轨迹下采样仍为空，未绘制替代线；D23 普通治疗 line01 未补齐，普通起手/弹道/命中仍用自身原素材；D33 独立 Combat 分支的 FSM 入口未证实，不把背向当触发条件。D24 当前模型在增援成功时已经完成落地结算，因此只显示真实落地效果，取消旧的“已落地后再飞来”错序；完整原空投运动器仍未复现。D30 默认 NeverTrigger 的原层仅保留依赖，不伪造普通攻击。

所有运行依赖与源码正常提交功能分支并推送 PR。原加工工作区、未接入稿、缓存和截图不作为游戏依赖，不提交；不创建启动脚本、ZIP 或 Releases。

## 运行与验证

普通启动仍进入十三关挑战。系统菜单返回测试选择，进入守军技能测试；第四至第六批为既有六星，第七批为新四位。

开发独立 Player 的显式 `-sixStarRosterSmokeTest` 观察器逐一经过正常角色入口、预加载、有限卡指针部署和自然自动开技，记录真实身体/特效 GPU 差异、暂停与重开。它不注入 SP、血量、目标、技能或伤害；这不是完整自然挑战或 OS 鼠标试玩。正式验证结果随后记录于 QA。
