# 经济方案设计约束

日期：2026-10-18。状态：用户已确认方向和部分参数，具体经济曲线已委托Codex设计，尚未完成模拟或实现；当前优先10月20日课程准备，不把本文件称为完成的数值方案。

## 已定输入

- 单次挑战6–10关、30–60分钟；起始1级，上限10级但较难达到，升级与刷新/追星竞争金币。
- 买经验与通关经验结合，升级不更换当前五张牌；每种怪九张、原十级费用档概率表保持。
- 开局随机低费保底占库；当前5费形象只留试验关；备战10格，购买先入备战，满仓可确认购买+合成。
- 刷新2金币，关间免费自动刷新、支持锁店。缺货0张不收费、1–4张同价且提示，不通过造牌填满。
- 招募价为c时售价：1星c、2星3c−1、3星9c−1；返库1/3/9。
- 金币收入需有基础收入、利息、连胜奖励与失败基础奖；没有连败和击杀金币。具体金额与时点待设计。
- 同挑战牌库跨关保留，新挑战重置；失败可只更换已有阵容重试，不得操作商店/装备或进行其他运营，不重掷商店/随机状态。

## 必须先解决的经济边界

**失败奖励与重试：** 若每次失败都发可用于后续运营的金币、又能无限重试，会形成刷钱。拟设计每关奖励账本，基础奖励按关卡结算只发一次、胜利差额单独记账；利息/经验/连胜也不能随重试重复产生。这只是待验证方案，不将“每关一次”的限定伪称为用户已确认；需明确失败奖励何时入账及连胜中断时点。

**普通经济局不买空卡池：** 需要同时检查总卡池和当前等级解锁的费用档。即使全局买不空，低等级只有1费可抽也可能局部缺货。不能为避免缺货违反已定概率解锁高费、补第十张牌或另加隐藏惩罚。

以各单位招募价c、初始九张计算，买下整个卡池的基础成本为 `9×所有单位招募价之和`。正常挑战的开局现金、赠卡价值和全部可领取收入总预算应与它比较；买经验/刷新还需扣去。该不等式只是全池同时持有的预算上界，不保证每个低等级都剩至少五张。还需逐阶段检查库存、备战/编队和星级占用。

**极端经济天胡：** 允许作为后续平衡目标，不预先实现正收益买卖漏洞、无限重试收入或新增肉鸽投资系统。具体通过哪些既有角色/羁绊构成合法经济联动，待角色和羁绊内容确定后设计；本轮不以“电表倒转”为名引入未授权机制。

## 后续数值交付与验收

1. 给出开局现金、基础胜负奖励、利息阶梯/上限、连胜阶梯/上限、结算顺序，以及1→10经验与买经验表；全部标明试验值。
2. 比较节省运营、均衡、频繁刷新三种策略，在6/8/10关长度下记录最终金币/等级/购买与刷新次数；检查10级是否确实稀缺。
3. 对低费重仓、三星占库、满备战、锁店、全部合法档缺货、失败后换阵重试进行库存/奖励守恒检查。
4. 先验证正常最高预算难以同时买空，再验证极端经济联动的例外路径；模拟不代表Unity已运行或玩家觉得好玩。
