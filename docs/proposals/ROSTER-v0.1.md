# 首批怪物与羁绊草案 v0.1

**2026-10-20后续澄清：用户要求进攻池采用明日方舟敌方怪物，维什戴尔为特例；中途v0.2误列干员已撤回。当前见[敌方怪物v0.3提案](ROSTER-ENEMIES-v0.3.md)。本页原创暂名仅留作比较，不直接用作正式怪物或套用旧技能/数值。**

日期：2026-10-20。状态：**Codex设计建议，等待用户修改，未确认、未实现、未做战斗平衡测试。**

目标：用6种怪物和2组羁绊，验证“随机招募/追星/转型能改变手动进攻办法”。本文件不覆盖GDD已定规则，不替换当前单只维维美试验关。名称仅为职责占位，正式角色身份和形象由用户选择；可以将认可的现有角色代入这些职责，不因暂名锁定美术。

## 1. 共用边界

- 继续使用攻击与护甲，单次伤害=max(1,攻击−护甲)。本批远程光弹也按这套伤害，不提前引入法抗/伤害类型。
- 所有怪物仍有合法目标停步攻击、无目标沿固定路线前进；不偷偷让高速怪忽略干员，也不改现有索敌/阻挡优先级。
- 招募金币与战斗DP分开；以下技能均不耗DP、不返还金币或DP。战斗不自然回DP。
- 每种9张、3同种同星自动合成、上限3星、同名限编队1张、实体数可超过等级等规则保持。重复部署和升星不增加羁绊计数。
- 羁绊等级按战前编队中不同怪物种类固定，阵亡/穿门/未部署不改变；只取最高档。以下两组都作用于全部友方怪物实体，不只限本标签成员。
- 6只均为普通可招募怪物的职责方案，不预定精英/首领身份，不新增首领数量限制。五费维维美仍只在现有试验关。
- 所有数值是原型起点。技能若无合法对象，不消耗技力；持续/弹药技能期间停止回技力，结束后从0回复。即发技能在成功施放后从0回复。该统一约定也是本草案建议，接入前需确认；普通攻击CD不因技能或取消选择自动清零。
- 护盾、回血、友方回技力和新羁绊都尚未实现，不把表现特效当作已有战斗能力。所有持续/动作/SP/CD共享现有模拟时钟。发射技能动作期间按GDD移动锁定规则处理。

## 3. 个体设计

### R01 铁桶怪：先站住，再让别人输出

- 外观方向：顶着铁桶的矮胖怪，漫画粗线条；只是概念描述，本轮不制作图片。
- 普攻：近战慢速敲击。
- 手动技能“硬顶”：初始SP3/需求9，回复1/秒；护甲增加6，持续6秒，不叠加。结束后恢复原护甲并开始回SP。
- 用法：先部署进入交战，接近强力攻击时开硬顶，再安排远程单位。按既定索敌保持规则承担前段火力，不带嘲讽或强制转移目标能力。
- 弱点：自己清敌慢；面对高攻击，护甲增益不等于无敌。提前部署过久会在后排抵达前倒下。
- 追星理由：更大生命池能承受更多轮攻击；三星不会自动获得嘲讽、无限部署或全新机制。

### R02 双刀小鬼：便宜，但需要保护

- 普攻：快速近战，每刀独立计算护甲。
- 手动技能“上头”：初始SP2/需求8，回复1/秒；5秒内攻击间隔变为原来的65%，攻击本身不额外加倍；不重置正在等待的普攻CD。
- 用法：跟着前排进入交战，技能窗口提供高频输出；1费可以作为追星路线核心。部署1DP支持同卡多次出兵，但次数和CD仍有限。
- 弱点：每刀伤害低，遇高护甲吃亏；脆弱且近战，不能凭移速绕过现行强制交战规则。
- 追星理由：攻击提升会改善护甲造成的低伤害，是追低费的回报；仍需测试是否会压过全部高费卡。

### R03 灯泡精：把队友的关键技能提前

- 普攻：远程小光弹，伤害低，仍按攻击−护甲计算。
- 手动技能“借个电”：初始SP4/需求10，回复1/秒；为4世界单位内另一名友方回复3SP，不超过上限。
- 推荐目标：排除所有灯泡精实体、阵亡、满SP和正在持续/弹药技能中的对象；剩余对象中优先SP完成比例最高者，平手按距离再按实体ID稳定排序。施放前高亮实际目标，玩家无需额外点第二个对象。
- 排除同名实体用于避免灯泡精互充循环；仍可重复部署支援其他角色。充能社只提高自然SP回复，不把“借个电”的3SP再次乘倍。
- 用法：帮助连弩鼠/锅炉巨怪或受压前排提前开技能。
- 弱点：单独上场收益低，只有1编队位时不作为推荐首发；保留商店可锁店，未凑齐配合前也可以先放备战，不强买。
- 追星理由：本版仅增加生命/普攻，回SP保持3，避免高星回技力失控；若试玩证明不值得追星，再改技能成长。

### R04 连弩鼠：能够转型的远程主力

- 普攻：中速远程，兼具铁皮帮与充能社。
- 手动技能“加急件”：初始SP2/需求10，回复1/秒；装填3发强化普攻，每发攻击为自身攻击160%，普通攻击间隔保持。消耗完3发后技能结束、开始回SP。
- 命中、弹药消耗与动作沿用项目已定时钟/发射结算方向；无目标时不凭空扣弹药，也不提前开始回SP。
- 用法：前期铁皮帮阵容中的后排输出，后期配灯泡精/药罐蛙转充能；升二星可以作为阶段主力。
- 弱点：部署3DP，反复部署消耗高；生命不够承担前排职责，强化箭仍单体且仍受护甲影响。

### R05 药罐蛙：用一个编队位换前排存活

- 普攻：低伤害远程药瓶，不附带毒、持续伤害或自动治疗。
- 手动技能“再撑一下”：初始SP3/需求10，回复1/秒；治疗4世界单位内生命百分比最低的另一名友方50HP，平手按距离/实体ID。无受伤对象不消耗SP；不复活、不提供撤退/返费，也不治疗自己。
- 用法：等铁桶怪受伤再治疗，或救即将失去的输出，配合充能更频繁支援。
- 弱点：占用一个原可放输出的编队位；救不到已经阵亡的单位。技能图标要展示实际治疗目标，避免玩家误判。
- 追星理由：治疗按50/85/140成长；需要测试回复是否造成不结束的拉锯。

### R06 锅炉巨怪：慢而有力，主动投资的选择

- 普攻：慢速单体远程重炮，不因为爆炸画面就默认范围伤害。
- 手动技能“开大火”：初始SP2/需求12，回复1/秒；装填3发强化炮击，每发攻击为自身攻击180%，攻击间隔不变；耗尽后开始回SP。
- 用法：面对较高护甲时，以较高的单发攻击取代部分高频低伤害输出。搭配灯泡精提前开火，或在铁皮帮4档阵容做核心。
- 弱点：4DP部署、技能启动慢、攻击间隔长，打少量残血目标浪费伤害；不能期待单卡碾压所有关卡。
- 定位边界：它是普通三费主力，维维美仍是独立五费试验角色，两者不共用牌库ID。

升星建议：1/2/3星HP和攻击分别乘1/1.7/2.8，最终值四舍五入；药罐蛙治疗同步50/85/140。护甲/射程/移速/SP/部署费/次数/CD不随星级自动变化，弹药技能按最终攻击取倍率。这里只是首轮便于比较的基线，不代表否定未来“部分角色升星增加部署数量”的方向；待第一轮实测再逐只调整。

## 5. 两组羁绊

### 铁皮帮：撑过接敌时最危险的几秒

成员：铁桶怪、双刀小鬼、连弩鼠、锅炉巨怪。

| 战前不同种类 | 生效效果（仅最高档） |
| --- | --- |
| 2 | 所有友方怪物实体首次取得合法战斗目标时，获得最大HP25%的护盾，持续6秒 |
| 4 | 替换2档：护盾为最大HP40%，持续8秒 |

护盾按实体分别记录，每个实体一场只触发一次；失去目标/重新交战不刷新，不因同卡再部署而给旧实体补盾。新部署实体有自己的一次资格。护盾按最终最大HP计算向下取整，先按原攻击/护甲结算伤害，再由护盾吸收，剩余伤害扣HP；到期直接清除。治疗不能补盾；未使用护盾不返费。希望玩家看到护盾图标和血条前额外盾值，而非仅后台加数值。

设计用途：让低费前排/近战和后排都能撑过接敌阶段，四铁皮要求4个不同种类、占4个编队位。护盾不是嘲讽，不改变守军索敌。

### 充能社：更早、更频繁地手动开技能

成员：灯泡精、连弩鼠、药罐蛙。

| 战前不同种类 | 生效效果（仅最高档） |
| --- | --- |
| 2 | 所有友方怪物实体的自然SP回复速度×1.25 |
| 3 | 替换2档：自然SP回复速度×1.5 |

不提高初始SP、不改变技能需求、不加快普攻/移动/部署CD、不影响战斗DP；满SP停在上限，持续/弹药技能期间仍不回SP。灯泡精直接补的SP不再乘羁绊倍率。加速技力条是预期可见变化，仍由玩家手动施放。

设计用途：允许用更多技能弥补部分普攻不足。它不是“带辅助就自动胜利”；玩家必须及时开技能，持续/弹药窗口也限制循环频率。

## 6. 看得见的三种构筑取舍

| 编队示例 | 羁绊 | 进攻思路与代价 |
| --- | --- | --- |
| 铁桶怪＋双刀小鬼 | 铁皮2 | 最早可形成的低费搭配；先桶后刀，对高护甲清敌慢 |
| 铁桶怪＋连弩鼠＋灯泡精 | 铁皮2＋充能2 | 3编队位接起两条路线；前排承伤、鼠输出、灯泡辅助；2费卡仍需等级4才能刷到 |
| 灯泡精＋连弩鼠＋药罐蛙 | 充能3 | 用手动技能和治疗维持后排，缺可靠前排；不是所有地图都适合 |
| 铁桶怪＋双刀小鬼＋连弩鼠＋锅炉巨怪 | 铁皮4 | 掩护持续输出与重炮，放弃完整充能；初次各部署一次合计10DP |
| 铁桶怪＋灯泡精＋连弩鼠＋药罐蛙 | 铁皮2＋充能3 | 用一个羁绊档位换治疗和更快技能；初次各部署一次合计9DP |

最后两组同为4编队位，追不同打法；部署1轮只是费用举例，次数和剩余DP还会影响下一轮。用当前DP12做纸面预算可以各完成初次部署，但这不是完整正式关卡DP定案；现有单只维维美关不能直接拿来接六卡。

3星低费追星与新主力的取舍：追双刀小鬼二星需要3张同名1费、招募总成本3Gold；一张连弩鼠2Gold，另可保留金币买经验。两者费用档/时机/职能不同，不应由一张“全局强度排名”决定。不要把升星合成当作买三张就能编队放三种怪。

## 7. 风险与验证顺序

1. **先验证职责**：铁桶怪＋双刀小鬼＋连弩鼠，比较不同部署间隔；不先做全部角色动画。
2. **再验证构筑**：接铁皮2、商店/自动合成/编队，检查一费追星和购买二费远程是否都有合理场景。
3. **最后验证转型**：增加灯泡精、药罐蛙和锅炉巨怪/充能，比较上述4编队位组合，再调整HP/倍率和经济曲线。每个可玩闭环另行确定任务，不在本草案一次承诺全做。

- 本批3只1费中辅助灯泡单卡偏弱；开局随机低费赠卡需测试其独立可玩性。建议首关允许普攻灯泡过关或在赠卡池中排除它，二者尚未选择，不能静默改赠卡规则。
- 护盾＋治疗可能造成持久拉锯，需要测敌我持续伤害；本游戏无时间限制，不能用加倒计时掩盖问题。
- 六怪单机卡池过窄，有限九张可能很快被玩家拿空；扩大正式卡池和经济预算才是长期方案，不能复制牌补满商店。
- 充能辅助可能压过输出，灯泡与高星循环需测；现方案排除同名回SP但不能据此宣称已证明无循环/必平衡。
- 高护甲如果让双刀只打1伤害，会使一条打法失去选择空间，教学防线应有可读信息和多解；所有数值均需实测。
- 当前三关验证流程应让等级4及2/3费有实际购买窗口；收入/经验曲线未实现，不擅自把“第二关必升4级”等建议登记为规则。
- 新增实现主要是护盾、治疗、友方SP选择和阵容羁绊；角色技能复用持续增益/弹药两类框架，不引入召唤物、复活、动态路径、新伤害类型或通用技能语言。

## 8. 给用户的修改入口

可直接回复“R02改成某角色；R03不要回SP；铁皮帮换效果”等。优先看：六只职责是否喜欢、是否愿意做辅助、两套打法是否有吸引力、双标签连接卡是否合理。数值可先不逐项审核，后续由原型测试调整；用户未确认前本文件始终为提案。
