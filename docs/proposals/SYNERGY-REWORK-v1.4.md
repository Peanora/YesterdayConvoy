# 感染、雪怪与泥岩培养修订 v1.4

2026-11-05 人类已确认本轮设计与具体接入范围。本文件覆盖v1.0–v1.3中这三条的旧门槛，其余六条沿用；数值为可试玩试验值。

## 感染生物：两种爆炸各自结算

保留2/4/6与主/副形态。爆裂为原体最终死亡后0.2秒追加35/65/85法术伤害，乘1+0.35×(星级−1)，范围1/1.2/1.3、上限2/3/3人。

有固有爆炸时，固有伤害类型、范围、延迟、寒冷继续独立。例：基础爆炸90物伤对10甲是80，2档额外爆裂35法伤对0法抗是35，合计115；不是把90整体乘倍率，也不是重复寒冷。二者命中不同目标时分别计算。

集群按原有规则平分固有爆炸预算，副体不复制寒冷；羁绊额外爆炸只在原体触发一次。复起的第一次倒下不算最终死亡；转化体、援军、巨像不递归复制。

## 雪怪小队：2/5档

成员：冰爆源石虫2费、雪怪狙击手1费、雪怪术师2费、凿冰人3费、霜星5费。四人仍只取2档，五个不同雪怪种类达到5档。按战前不同种类固定，不受是否部署或阵亡影响。转职装备尚未接入，因此当前静态名单仍需原五种入编队，但天气触发不依赖霜星部署或技能。

| 效果 | 2人 | 5人 |
| --- | --- | --- |
| 碎冰伤害 | 50法伤 | 120法伤 |
| 半径/最多目标 | 0.9/2人 | 1.5/5人 |
| 同一目标冷却 | 4秒 | 3秒 |
| 是否消耗原冻结 | 是 | 否 |

两种不同的原始编队卡在2.5秒内直接命中同一冻结目标触发，支援/分体不凑来源。按雪怪平均星级，每提升一星伤害+35%。角色自带的凿冰人冻结增伤仍独立。

2026-11-06人类确认最新双触发：必须5档；每次成功的羁绊碎冰积累1点寒意，达到3点自动发动8秒全图暴风雪并清零；霜星手动冰封起手也能发动同一场天气。一次碎冰命中多人只算1点。天气期间的碎冰仍正常结算伤害，但不为下一轮积累、不叠加或续时；成功启动天气才清零，结束后从0/3重新积累。自动冰环不启动天气，不足5档的霜星开大也不启动。转职装备尚未实现，未来需进入编队羁绊快照。

0/2/4/6秒各对存活守军造成`(60+目标最大生命×2%)×Q`法术伤害并尝试施加寒冷，`Q=1+0.35×(战前雪怪平均星级−1)`，复用现有法抗与实际伤害跳字。这是试玩试验值：1000生命、0法抗、平均一星的守军每次80，共320；平均三星共544。伤害标记为派生，不再产碎冰、深池火种或海嗣命中资源。死亡目标不重复受击。

寒冷使攻速变为70%，不降低单次攻击力；羁绊战斗中第二层寒冷变1.2秒冻结。额外风雪不延长当前冻结；由它产生的冻结结束后，同目标保护3秒；保护或已冻结均不免疫寒潮伤害。角色本身冰封和自动冰环的伤害/控制保持。结束时不清除仍有效的目标状态，其后正常攻击若满足原碎冰条件可以积累下一轮。天气表现和提示跟随实际模拟时钟，左侧显示寒意0/3至2/3或天气剩余时间。

### 培养与经济

- 2人：解锁I阶段与投入；4人：允许III且培养效率提升；5人：具备IV成员资格。
- 正式战斗胜利且至少两种小队成员真实直接命中或受击：+3培养。4人及以上且巨像也真实交战：额外+1，最多4。
- 不因补给、单纯放置、失败、中途重开发培养。正式关每次结算一次。
- 准备阶段投入，每个唯一关间最多10金币。刷新/锁店/反复开商店/重开战斗不刷新额度；失败投入不扣金币。
- 总投入是累计门槛，不是升级时再逐档扣费；出售成员不返还。新挑战经验和投入清零；低档成员不足时本场降档，累计进度保留。
- 利息仍按既有金币余额每10得1、上限5。投入使余额减少，自然可能影响下一次利息，不另增经济规则。

### 成本与可达性

五人全二星最低招募费用为3×(2+3+3+4+5)=51金币，加80投入共131；还要支付升级、刷新和其余阵容。常规约300金币总收入中会形成显著机会成本。投入80至少跨8个关间；24培养也要求较早凑到两人、后期凑四人并让巨像参战。不能靠最后一轮买五张卡即时跳IV。

本轮不把商店概率写成保证成型；正式高胡成型率与长期平衡仍需批量完整局试玩。终极收益的验收是当前最难六星防线真实清场，不是保证任何未来新增守军或所有地图必胜。

## 操作与实现连接

进入“羁绊自由试验”或三阶段挑战，准备面板右侧选择“巨像培养”；显示经验、投入、下一档条件与本关间额度。可投入1/5/10金币。自由试验另有I/II/III/IV预置，明确标注为测试设定；IV会使用当前完整六星防线，拖动右侧巨像卡到红门验证，可暂停部署。

`BattleShopRun`保存跨关培养和累计投入，`ShopTrialModel`负责原子扣金币；`GolemGrowth`统一判断门槛，`CampaignController`把编队星级和进度写入每场只读快照，`ManualBattle`实际结算交战/伤害/控制。左侧`SynergySidebar`说明档位，右侧`GolemTrainingUI`提供操作。场景锚点生成装置配置，`Gramophones`结算归属/攻疗，`MudrockVfxView`表现已确认素材。

验证结果与限制以docs/QA.md和STATUS为准；本文件设计描述不是测试通过证明。
