## 2. 技能与实现边界

- 米格鲁可沿用旧R01护甲持续强化的职责；具体护甲、SP与时长重新试验，不照抄原作数值。
- 玫兰莎改为攻击强化，旧R02攻速增益与相关基础攻击/间隔表不再适用；不能仅换名字还保留双刀外观。
- 史都华德改为攻击敌方的术师，取消旧R03直接给队友3SP的技能，因此不再有灯泡精单卡无法发挥辅助的问题。现阶段仅攻甲的伤害规则仍有效，是否增加法伤/法抗是后续待定规则；优先索高护甲等天赋也需单独确认，不静默覆盖现有索敌优先级。
- 能天使以短时多段射击为技能方向，具体选用哪项原作技能、手动/自动触发、段数与SP表待用户确认；不能把原作自动触发技能无说明改成手动却声称完全复刻。现有满SP手动技能规则保持，先提供手动改编方案。
- 白面鸮以治疗为普通行动、技能提高治疗效率，技力光环为候选天赋。**这需要新增医疗行为：何时为队友停步、何时继续走，以及治疗/敌方攻击目标分离**；未确认前不让现行怪物脚本自动获得该例外。光环候选只在至少一名白面鸮实体存活在场时生效，同名不叠加；与固定战前羁绊等级分开计算。具体叠加公式待定，旧R05直接治疗50点/SP数值不能视为新角色定案。
- 陨星应有真实范围伤害才能体现特色；当前M01爆炸仅表现，不等于已实现AOE。半径、二次目标/遮挡/命中结算与技能改编需设计及测试，旧R06单体三发180%不再作为新角色定案。

没有改动已经确认的经济、牌库、编队、暂停、动作移动锁和胜负规则。任何医疗/范围伤害/天赋/回复类型的扩展都先写清规则，再分闭环实现。
