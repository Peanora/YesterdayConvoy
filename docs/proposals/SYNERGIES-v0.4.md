# 羁绊构筑、五费专属与银狼接管方案 v0.4

日期：2026-10-20。设计负责人：干宸骅；整理：Codex。

**状态：用户同意本轮方案写入项目；设计方向已采纳，候选费用、阈值、增量和表现名称仍待试验；所有新增玩法均未实现。** 本文与[GDD第7节](../GDD.md)共同作为后续设计入口，替代[v0.3六种敌方候选](ROSTER-ENEMIES-v0.3.md)作为内容扩展依据，不抹去历史。当前单卡Demo、代码、场景、Prefab、美术和试玩包不变。

## 1. 本轮确认与证据边界

| 层级 | 本轮记录 |
| --- | --- |
| 已确认方向 | 常规招募主体是《明日方舟》敌方单位，采用原名、剧情组织/小队/族群，多标签交叉；防守方仍是干员 |
| 已指定角色 | 加入敌方塔露拉；维维美继续作为特例，银狼为新指定乱入特例，不扩充其他干员或跨作品角色 |
| 已采纳设计方向 | 九条常规羁绊分别提供培养、连锁、协同、转化、运营或适应玩法，不以纯属性加成为主要吸引力 |
| 已采纳专属方向 | 五费专属作用于准备阶段选择、资源分配或角色联动，不能把个人主动技能/天赋改名后当成专属羁绊 |
| 银狼已确认 | 保留头号玩家、常规羁绊接入、升星继续选择、补丁；三星五费后接管本局，包括增加经验、提升等级 |
| 当前细案 | 固定五费；1/2/3星分别有1/2/3个不同接入槽；升级时新增选择并可调整一个旧选择；具体交互待实现验证 |
| 试验/待定 | 其他候选费用、羁绊阈值、部署参数、伤害与回复数值、补丁2金币/每关一次、模块成本和星级扩展 |
| 接管待定 | 加经验/升级的具体增量和重复次数、能否突破10级、金币/免费刷新/更多补丁等扩展权限 |
| 未实现 | 多卡商店与跨关经济、以下新怪物和新技能、普通/专属羁绊、培养、接入、补丁及管理员面板 |

“局外”在本文指当前挑战的准备/关间阶段，不是增加账号养成或局外永久科技。新挑战重置构筑与专属进度。

## 2. 三个不同层面

| 层面 | 解决的问题 | 例子 |
| --- | --- | --- |
| 角色技能/天赋 | 这个实体在场上如何战斗 | 维维美六发爆裂黎明、塔露拉日冕、爱国者阶段转换 |
| 常规羁绊 | 这套阵容围绕什么机制运作 | 泥岩小队养巨像、雪怪碎冰、游击队积累军令 |
| 五费专属 | 抽到该卡后，怎样改变构筑和运营 | 调兵、指定搭档、选择巨像模块、银狼接入与补丁 |

五费专属在一星便能提供玩法，二星拓展选择，三星可以出现强烈质变；不得把全部体验锁在三星五费之后。不设五费/首领专属上场数量限制。专属随角色进入有效编队提供构筑入口，个别战斗联动仍需相关实体实际在场，逐项配置；备战持有不默认激活。

## 3. 原作身份与多标签

- 整合运动、深池是组织；雪怪小队、游击队、泥岩小队是小队/部队；萨卡兹、感染生物是族群。它们可同时作为羁绊维度，不声称属于同一级组织。
- 野生源石虫不统一计整合运动；猎狗、游击队猎犬和冰爆源石虫按相关操纵/编制关系计战术标签。
- 泥岩小队采用独立活动阶段归属，不因曾参与整合运动就自动给全队挂整合运动。
- 爱国者可同时计整合运动/游击队/萨卡兹。泥岩巨像是造物，不计萨卡兹。塔露拉不因火焰联动计深池。
- 牧群把宿主与控制者梅菲斯特放在同一构筑体系，这是本作归类；梅菲斯特不因此被写成宿主。
- 海嗣羁绊合并候选海怪/海嗣单位，属于本作归类简化，不将它们一律写成深海教会成员。
- 银狼的接入使用独立“模拟接入”标识，可以在机制上计入族群/小队羁绊，不声称她在原作是萨卡兹或雪怪成员。
- W与维什戴尔不因为不同称呼拆成两种角色来凑人数；现有显示名维维美保留。

按战前编队不同种类计人数，备战不计，同名仅编队一张；部署多个实体、升星、死亡或穿门不增加或降低本场羁绊人数。每条仅取最高达成档，多个羁绊可以同时生效。高档描述应完整包含本档所有效果，避免误解为低档数值叠加。

## 4. 九条常规羁绊

下列阈值是试验候选，不是已平衡数值。标注“全队”包括不带该标签的友军；专属加成可再指定对象。所有新增状态、伤害类型、保护、转化和召唤都是未来工作，不宣称现有攻击减护甲模型已经支持。

| 羁绊 | 候选阈值 | 核心机制与作用对象 | 追求与取舍 |
| --- | --- | --- | --- |
| 泥岩小队 | 2/3 | 2档提供本局持续培养的泥岩巨像支援，每场可付DP召唤一次；通关和不同小队成员参战提供有上限的培养经验；3档开放最终阶段并加快培养。巨像掩护/协助全队 | 提前投资培养与立即追星/升级竞争；正常两三场应看到成长，不拖到最后一关才变化 |
| 雪怪小队 | 2/4 | 2档由不同种类友军命中冻结目标触发碎冰；4档碎冰冲击向附近守军传播寒冷。全队可以参与连锁；碎冰消耗冻结，同目标设再触发间隔 | 找齐施寒冷、冻结与击破组件；不能无限冻住所有守军 |
| 游击队 | 2/4/6 | 全队不同卡种实际交战积累有限军令；满后手动发起协同攻击，各单位攻击自己的当前合法目标。4档形成前排架盾/后排齐射，6档可分两段发动 | 安排前排与输出入场时机；军令不通过空等或单个实体反复挨打无限获取 |
| 牧群 | 2/4 | 全队前若干个符合条件的死亡实体转化为弱宿主，转化体不能再次转化；4档继承一种基础特点。总次数有限，转化体暂建议不扣蓝门防御，主要延续交战 | 第一批承伤、第二轮接力；不复制商店牌、不形成无限复活 |
| 深池 | 2/4 | 全队可利用火种：2档使带灼烧守军死亡后留下火种并传播，4档积累一次手动引爆机会；范围与次数待试验 | 先击破薄弱目标打开密集防线；同一死亡事件仅结算一次 |
| 感染生物 | 2/4/6 | 战前为感染生物卡选择集群/甲壳/爆裂一种形态，4档增强所选功能，6档可选两种。其他友军可利用其承伤、削甲、爆炸与突破窗口 | 根据下一关选择数量、防护或死亡爆炸；不改商店卡数量、不强行给所有生物套同一动作 |
| 整合运动 | 2/4/6 | 全队不同卡种依次部署完成集结，使下一次合法部署附带有限士兵援军；高档可选近战或弩手支援。次数、数量与穿门伤害待试验 | 多兵种调度与连续进攻；援军不成为永久卡、不靠召唤套召唤无限产生 |
| 萨卡兹 | 2/4/6 | 战前指定一名全队范围的承契者，其他友军第一次进入危险血线时为其积累有限力量；满后形成强化窗口 | 决定核心和保护方式；同实体反复治疗/受伤不无限刷贡献 |
| 海嗣 | 2/4 | 战前选择适应方向，海嗣单位通过实际交战有上限地推进形态；队友可利用其提供的保护或突破能力，具体模块待定 | 针对守军而非挂机成长；成本高于其他路线，后置制作 |

### 4.1 关键细案

巨像培养暂分承伤、重击、范围震击三个阶段，培养等级不等于卡牌星级。上一批39种敌方候选中的泥岩巨像移出普通商店候选，转为羁绊召唤物；不同时维持两套同名不同成长的巨像。该调整是内容设计，未删除现有资源/功能。

感染生物三种选择：集群增加单次弱小实体数量并降低单体强度；甲壳减少数量、强化第一轮防护；爆裂使部分临时小虫死亡后爆炸。具体DP、次数和伤害需同预算比较。高速单位依然遇到合法目标停步，不自动越过干员。

雪怪的寒冷、冻结和碎冰需要独立状态与触发窗口；不把两段不同效果重命名后叠加成无限控制。火种与冰冻是否有元素互斥尚未设计，不能擅加相互抵消规则。

## 5. 八名五费专属

以下专属名称除“头号玩家”等借用称呼外多为暂拟，不能作为原作已有技能名或组织名宣传；人物和阵营名称按原作。所有五费候选招募价为5金币，部署DP另配，不统一为5。

| 角色 | 专属名称候选 | 已采纳的构筑机制方向 | 对象/成本及待试验项 |
| --- | --- | --- | --- |
| 塔露拉 | 整合运动领袖 | 准备阶段在两种不同整合运动普通卡之间调配有限部署次数 | 仅正常编队内普通卡，首领不参与；供出方至少留一次；一星暂调一次、二星扩展。属于明确专属例外，不改基础卡资产 |
| 爱国者 | 并肩之约 | 战前指定前卫与支援搭档；前卫承伤帮助支援充能，支援放技能反过来保护前卫 | 从正常编队选择，不增人口/羁绊人数；每实体技力独立，通过明确事件额外回复；触发间隔和三星第二组待试验 |
| 霜星 | 寒地训练 | 战前让普通怪学习制造寒冷、利用碎冰或保护阵容的一种战法 | 不增加雪怪羁绊人数；受训数量、可换时机和成本待试验；暴风雪依然是角色技能 |
| 泥岩 | 岩石的朋友 | 准备阶段为已培养巨像选择功能模块 | 城垒保护附近友军/攻城削甲/震击范围重击；培养进度保留，一星能选一项，二星模块组合待试验 |
| 梅菲斯特 | 牧群名册 | 战前把有限转化名额分配给指定普通卡种 | 优先级、宿主继承特点和无普通牧群时的基础名额待试验；同一受体不递归转化 |
| 蔓德拉 | 石像工坊 | 准备阶段选择制作地面承伤或远程支援守墓石像 | 临时支援体仍需DP部署，来源/次数独立保存；不变成额外永久卡，不解锁任意地图位置部署 |
| 维维美 | 军火生意 | 准备阶段花金币为普通远程物理卡选择本场弹道改装 | 爆炸箭/贯穿弹候选，作用目标、价格及覆盖次数待试验；不新增独立通用装备系统，不改现有六发技能与动作锁 |
| 银狼 | 头号玩家 | 常规羁绊接入、准备阶段补丁，三星五费后接管本局 | 详见第6节；一星有完整选择，三星接管是终局奖励，不是普通主动技能 |

五费可分为运营投资、阵容组织、体系深化三类。不要因为需要专属就为每张卡引入一个互不兼容的大系统。优先样板为银狼/泥岩/塔露拉/爱国者，具体实现次序另行确定。

## 6. 银狼：头号玩家

### 6.1 身份与接入

银狼为用户指定的《崩坏：星穹铁道》乱入特例，采用固定五费方案；保留星核猎手身份，但不为此追加其他铁道角色或开启凑不齐的多人档位。头号玩家是独立专属，模拟接入标签另列，不改变原作身份。

| 星级 | 本轮记录的接入方案 | 其他能力 |
| --- | --- | --- |
| 1星 | 从已开放常规羁绊中直接选一个 | 准备阶段可购买补丁 |
| 2星 | 保留主卡选择，再接入一个不同羁绊；可调整一个旧选择 | 补丁升级幅度待试验 |
| 3星 | 再接入一个不同羁绊，最多三个；可调整一个旧选择 | 达到三星五费，解锁本局管理员接管 |

接入从完整已开放列表中选，暂不增加随机三选一。不能重复同一标签，不能接入别人的专属；原生标签和模拟标签重合时去重。一张银狼可对不同羁绊各贡献一种，但不能充当同一羁绊的两名成员。

接入保存在卡实例；自动合成继承编队主卡的选择，不合并三张材料的接入列表来超槽。主卡选择缺失或因版本失效时需明确补选，不能静默随机。备战银狼的选择不提供编队贡献。选择随本局保存，开战快照锁定；每个准备阶段自由付费重选尚未定案，不能默认无限改。

例：1星接入泥岩小队，补早期养巨像；2星接入萨卡兹，形成承契体系；3星接入游击队，再叠协同军令。仍按队伍真实卡种和各自阈值计算，不保证这三个选择单卡就能激活全部高档。

### 6.2 普通补丁

| 补丁 | 本作效果建议 | 事务和限制 |
| --- | --- | --- |
| 商店重编 | 选择一个商店槽，按该槽原费用档从指定常规羁绊合法库存重抽 | 被替换牌先按事务返库，候选占库；无合法候选时不收费且保留原槽；不生成指定同名保底，不越级、不超过九张 |
| 部署优化 | 为指定编队卡提供本场一次部署CD重置机会 | 仍支付DP/扣次数，不恢复已耗次数；完全暂停不推进战斗，具体触发交互另设计 |
| 漏洞植入 | 指定一个守军，被三种不同友军命中后瘫痪一次 | 按单位种类去重，不靠同卡多实体凑三种；目标失效、控制免疫及触发间隔待设计 |

2金币、每关一个补丁为试验初值；与买经验、刷新和追星争夺金币。购买、出售、反复换阵容不能重置本关购买记录。补丁效果不直接给银狼伪造其他五费专属，不要求在战斗中打开商店。

### 6.3 三星五费：“接管《昨日圆车》”

**用户本轮明确要求，必须保留的终局玩法：** 银狼达到三星五费后，解锁本局管理员接管，能主动加经验、加等级等。不能替换为“伤害翻倍”或再包装成一个普通战斗技能。此奖励允许明显超出普通构筑强度，不为常规平衡把它削成微小属性加成。

接管入口建议表现为银狼覆盖准备界面，显示“头号玩家已取得管理员权限”；已有接入与补丁能力继续保留。初次触发、入口位置与文字属于表现方案，未制作。

| 指令/行为 | 状态 | 本作记录 |
| --- | --- | --- |
| 增加队伍经验 | 用户已确认功能方向 | 给当前挑战的队伍经验加值，具体每次增量待定；不是给银狼升第四星，也不是巨像经验 |
| 提升队伍等级 | 用户已确认功能方向 | 可以直接提高队伍等级并更新相应编队槽/后续商店概率；具体步长待定，不由银狼伤害技能触发 |
| 是否能重复使用上述指令 | 待定 | 可重复点击/每阶段次数/一次性大量奖励等尚未决定，不自行加一个未经确认的永久一次限制 |
| 是否突破常规10级 | 待定 | 普通局仍为1—10级；若接管允许突破，需要明确例外等级上限、额外编队格、概率表和UI，不能只越界改一个数字 |
| 加金币 | 参考原作的扩展候选，未确认具体权限 | 可以作为接管爽感候选；金额、次数及利息处理待定，不写成已实现或用户指定金额 |
| 免费刷新/补丁免成本或解除次数限制 | 扩展候选，未确认 | 接管后的运营特权另配，不能提前在一/二星生效 |
| 调整守军生命/蓝门防御/直接判胜 | 未授权为已定功能 | 不因原作能改竞争对手血量就直接引入；若以后采纳需定义胜负事件和UI |

拟定边界与数据约束：

1. 银狼通过正常九张基础牌、三合一规则达到三星，不因头号玩家提前复制材料；固定五费方案不照抄参考作的3→4→5费升阶。
2. 建议在准备阶段持有且编入三星五费银狼时首次解锁，再由本局状态保存权限。卖卡后权限是否保留尚未定案；首次解锁不能被反复买卖触发多份一次性奖励。既有战斗中不发生升星，因而无需借此绕过战斗内禁止运营的规则。
3. 管理员是游戏内玩法权限，不是编辑器、系统终端或文件读写权限；新挑战清除。默认入口放准备阶段，战斗内只读展示；若要允许战中修改等级/编队须另行明确，不能破坏本场快照。
