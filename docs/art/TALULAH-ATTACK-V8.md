# 塔露拉普攻 V8

2026-11-04，任务[#58](https://github.com/Peanora/YesterdayConvoy/issues/58)。用户经过V2–V8工程外预览后确认接入，最后一次要求是火焰不得在角色蓄力时提前出现。

## 运行连接

EngagementView的私有普攻入口取得本次真实攻击者的原动作信息与攻击间隔，交给内部TalulahAttackVfx。火焰只在真实CombatShot已命中后出现；没有新增伤害或改变0.65秒命中、1.7秒普攻周期及火雨。混编按本次攻击者读取，不使用编队第一张卡的参数。

V8看稿使用原动作1.0333333秒OnAttack之后的时间：0–0.045秒起焰，0.045–0.10秒快速展开，0.10–0.31秒拖焰，0.31–0.68秒余烬退场。游戏原人物已将OnAttack映射到真实命中，特效恢复段也按同一映射播放，避免将浏览器1.03秒照搬到游戏0.65秒命中之后。未改人物动作或攻速。

火焰位于攻击者根点的相机平面；实际GPU截图检查后，将画布适配为3.70×3.29世界单位、中心向相机上方偏移1.50，避免下方焰尾被地面裁平。左向图集按实际目标侧整体镜像，连锚点一起翻转。每个并发攻击使用独立MaterialPropertyBlock，避免多个塔露拉串帧。暂停读取冻结的战斗时钟；结束隐藏，重开/换关清理。材质保持深度测试，不能穿过实体地形。

新TalulahAttackFlipbook.png为1536×1024 RGBA、4列3行12帧；相邻帧按透明度预乘插值。PNG保留生成原字节与Alpha，材质复现V8看稿的暖色清边和亮芯保留，减少灰晕与误删高亮。不再叠加上一版细火痕、重复火舌或烟团。

图集、私有Shader及必要.meta随源码交付。保留旧CC0火焰/烟雾和Shader，因为火雨与余的火墙仍使用它们；没有删除共享素材。所有新资源通过Resources打入Player，不依赖工程外V7/V8预览或联网下载。
