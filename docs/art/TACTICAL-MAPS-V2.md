# 双地图多门 V2（2026-10-27）

人类已确认项目外多门 V2 的美术方向和精确布局后接入。泵站回廊4红2蓝、4条固定路线；金叶环庭3红2蓝、3条固定路线。布局见同目录 `TACTICAL-MAPS-V2-LAYOUT.json`，该文件由审批稿提取，格点转换为 `(x−8.5, .04, 5−y)`。各红门固定对应一条路线与一个蓝门，所有蓝门共享本场防御。

## 美术与可玩入口

- 两图都从主选择页进入，沿用主场景拖动卡牌、顶部费用/防御、暂停、技能面板和胜负结算。作战中没有切换地图按钮，也没有旧设施关的底部诊断按钮。
- 使用真实世界坐标的地面、台阶、建筑、管线、遗迹、树冠与门线框，角色沿配置路线移动。概念图没有被当作整屏碰撞背景。保持主镜头60°正向俯角、FOV24°、无横向偏航/滚转，仅重新构图以容纳18×11格地图及上下HUD。
- 泵站采用灰冷混凝土、白色设备罩、暗色水渠和克制的警示漆；环庭采用苔石、断柱、金叶和溪流边界。两图沿用同一角色/HUD体系，环境主题有意不同。
- 目前是塔露拉攻打原八人防线的可玩地图样板；试验值DP24、部署费2、最多12次、守方防御1。不是正式多角色编队或最终关卡数值。拖到红门时预览其完整路线；守军采用紧凑血条、隐藏名称标签。每人独立攻击、阻挡、治疗与现有动作保留；没有擅自补齐八人完整技能。

## 新增素材与来源

`Assets/_Game/Art/Environment/TacticalV2/` 仅三张实际运行PNG：`city-concrete.png`、`ruins-sandstone.png`、`autumn-canopy.png`。均由本次 OpenAI 内置 image_gen 生成，使用已确认的两图概念作为参考，不含角色、文字或游戏截图。原始分辨率1254×1254；树冠具有真实Alpha 0–255（697,320个完全透明像素），不是棋盘背景假透明。Unity导入使用Bilinear/生成Mipmap、2048上限，地面Repeat、树冠Clamp/Sprites透明混合；没有声称纹理已严格无缝。

工具、完整提示词、SHA256、尺寸与透明度记录见 `TACTICAL-MAPS-V2-GENERATION.json`。地图概念、放大看稿、路线动图、原始加工文件继续在项目外美术预览工作区保存，不作为运行依赖上传。三个成品PNG和必要meta随源码交付。原人物素材的来源与权利记录继续沿用现有各角色清单，本轮没有把非商业意向或上传决定写成版权方授权，也没有把AI材料宣称为CC0。平台使用条款没有在本轮作独立法律审查。

## 旧图退役与兼容

删除原工业转运站、雪原中继站、芦苇水道的预览/可玩场景共六份以及切图组件和旧生成入口。保留仍被引用的材质/GUID。原怪物、八人防线与队友特殊能力没有删除：祭坛、封地、留声机、芦苇、神经、枷锁、火焰、蔓德拉等回归改用 `Assets/_Game/Tests/Fixtures` 的中性测试场，不进入正式构建或地图选择。游击队/爱国者独立测试也改用中性底板，避免继续依赖已退役地图。

## 数据连接

`DefenderTrialDefinition` 保存地图静态配置，`DeploymentLane` 在开战时复制各路线；`ManualBattle` 按落点选择红门并将路线/蓝门身份绑定到实体，原统一时钟、费用事务、索敌与穿门结算继续工作。`TacticalMapEnvironment` 只生成显示，不修改碰撞或战斗状态。`DefenseTrialMap` 保存并恢复借用的相机、原地图和门显隐，重复返回/重入以及场景卸载均有GPU场景回归。
