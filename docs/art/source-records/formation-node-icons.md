# 整备顶栏节点图标

《明日方舟》参考：[「傀影与猩红孤钻」官方静态导览](https://pbs.twimg.com/media/FXcsrHEaIAEhd_4.jpg)，画面左侧 NODES 区的作战、事件、补给和首领靠轮廓区分。此处对照静态图，不涉及播放时间。原导览仅供参考，未复制其图案或素材。

图案为项目外看稿中的原创矢量。按用户修订互换看稿的物资箱和切面球，不再重画。其余四枚保持看稿的轮廓。顶栏沿用本作原有节点配色、底框和点击区域。

源稿为同目录的 `formation-node-icons.svg`。透明白色图集按从左到右、从上到下排列：战斗／遭遇／奖励（物资箱），补给（切面球）／战备／首领。各格 64×64，运行中渲染成 22×22 并按节点着色。
