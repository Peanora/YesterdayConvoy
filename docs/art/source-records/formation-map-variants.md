# 卫戍协议三张地图

三张地图采用用户确认的独立布局。原作对照是本机客户端里的同关卡 `sub_01` 官方缩略图和实际场景包，前者核对地面、墙体和主要景物，后者核对网格、材质槽和对应图集。原缩略图为静态资源，无播放时间点。

| 现役地图 | 原作规程与资源族 | 适配 |
| --- | --- | --- |
| 叙拉古街庭 | #05 · `map_syracuse_metro` | 中央植被岛、双向环街、后侧露台。沥青面从同包图集取样，重排顶面 UV。 |
| 蓝冰雪谷 | #09 · `map_icewild` | 后侧冰脊、可踏的斜向冰带、门前高台。冰面与通行平面对齐，以保持脚点与地面特效接触。 |
| 金饰回廊 | #12 · `map_ltny2` | 两格宽的金边直道、两翼高台、对称台座和较宽的前庭。 |

每张地图的本地 `source.json` 保留原包相对路径、版本、SHA-256、原网格及材质对象 ID、原图集校验值、摆放和守军格位。关卡及对照图来自客户端补丁 `26-11-13-06-34-18-84612175`，材质资源包来自流式资源 `26-10-20-11-10-38-04170990`。共接入 56 个网格变体（含一项沥青 UV 变体）、6 张图集。原资源的再分发许可尚未核验。

发布场景共用红蓝门、机位和角色表现。三案各有独立的存盘 Prefab，`FormationMapTools.Apply` 从已有清单重新保存网格、材质和场景引用。运行时只启用已经保存的地图。环境使用既有战场材质的兼容光照、裁剪和色调，可通行铺装没有减速、伤害或强制路线。新地图的场景摆件采用确认稿的静态表现。
