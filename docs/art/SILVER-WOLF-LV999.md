# M41 银狼 LV.999

在怪物测试选择页点「进入银狼测试」，拖卡至红门。也可从 Windows Player 使用 `-silverWolfTrial` 直达。单怪测试使用现有棋盘和源石虫地面模型，高耐久便于看完一轮。正式关卡照常攻击守军，五费、九张库存、部署8 DP；本轮不新增准备阶段补丁或管理员接管。

常态沿路线行走，进入射程后停步并出上勾拳；动作从右向源稿按屏幕水平方向镜像，身体、飞行道具与落点分别对齐。满28技力后点场上银狼，再点「无敌玩家」。若已出拳，先收势再变身；1.43秒内亮起星形大墨镜，随后可飞行接敌。每有合法目标开一盒，独立等概率三选一，允许连抽同款。一轮三盒，最后一盒4.60秒动作播完回常态。暂停冻结模型、出手和特效；两倍速同钟推进。
