# 早期自制特效原作替换范围

2026-11-06，人类要求按塔露拉的原素材事件绑定流程优化其余早期自制特效。本页记录真实范围和进度，不能把原包取得或Prefab名字存在写成实机完成。

## 已保留的例外与原层

- 塔露拉已原作的A/B/阶段/命中与用户明确确认的橙色穿透火浪保留。
- 爱国者、泥岩/留声机、梅菲斯特、蔓德拉已接入原独立特效保留，不覆盖队友成果。
- 所有角色原动作、正背面和望的原棋子继续使用。
- 维维美按本轮要求先修左右/诱导/恐惧步态与六发技能真实2.2格半径群伤，保留用户GIF与表情，不擅换正常皮肤。
- 血条、跳字、路线、选中/范围预警属于信息层；本作羁绊组合没有一对一原规则，保留其玩法，原公共粒子适配不能登记成原机制。

## 制作与接入边界

复用已验证的项目外NativeJobs/Vulkan原Shader采样、原依赖闭包和HDR透明图集编码；先跑一个低帧代表层，再批量。身体/施法者/目标/地面/持续层分开，挂真实事件和同一模拟时钟；暂停、取消、死亡尾段和重开必须核对。

本轮新素材在项目外 `2026-11-06_原作特效整备-v1` 准备。人类已看过守军/怪物动态看稿，并明确确认“采用看稿，按清单逐批直接接入其余”，包含尚未展示的同范围剩余层，不需为每个片段重复审批。下载记录不是开放再分发许可；原权利状态保留。接入后源图/清单/必要meta按持续规则随源码推送，原包、预览工程和缓存不入Git。

## 当前接入方式

- `OriginalCombatVfxArt`严格读取源清单，使用既有图集缓存与塔露拉HDR透明解码Shader；保持每段实际裁边、脚底挂点和世界单位，不统一强拉尺寸。
- `CommonCombatVfxDirector`独占普通弹道/命中、生成死亡和低星公共强化；角色专属导演独占其技能层。延迟、空帧、取消和结束时也保持所有权，避免旧圆环重新冒出。
- `FrostSealView`、`FlamerazerEffectView`、`NeuralEffectView`、`MonsterOriginalEffectView`读取已有冰封、喷火、海嗣、枷锁与转化事件；守军独有层由`DefenderSkillVfxView`及`YuFirewallVfx`读取原事件。
- 进关按当前编队/守军预热，构建时纳入既有预处理流程；不让首次攻击临时解码所有角色。终局只延续已发出的实际特效尾段，战斗逻辑时钟不恢复。
- 感染/巨像/碎冰为本作组合机制，只使用原公共素材适配，不能称原客户端完整规则。缺少原脚本的挂点、连线端点、结束事件和霜星复起时间映射须在来源记录中注明。

技术首批：D27原材质/原Shader采样→图集→实际事件→Windows D3D11 Player，8项检查通过，同刻效果开/关相机对照有5467个明显变化像素，已检查实际中心棋盘截图。它证明共享读取与渲染路线，不代表其余全部角色逐项验收。全量接入的最终测试与缺口见`docs/QA.md`及两份来源清单。

最终接入：194段独立原层/199页/12369帧，463逻辑及133当前场景用例最新结果通过。最终EXE初雪与余各8项实机检查通过；足底层改为保留原PPU与挂点的显式地面投影，轻透视保留自然远近差异，未用Always深度掩盖裁切。已查看真实D27完整法阵和D22原火墙画面。

仍有明确附加层缺口：安赛尔/银灰个别原拖尾、望额外独爆/原邻接线、荒芜拉普兰德额外自身UV旋流，以及余原StopEmitting尾部。现有可玩事件已按各自来源或明确公共适配替换，不能把这些附加层记为完全还原；来源说明保留真实权利状态。
