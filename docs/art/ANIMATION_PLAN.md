# 怪物移动动画优化目标

## 最新执行依据：用户GIF替换（2026-10-19）

原纸片关节/转身路线在正常M01中由用户四GIF替代；本轮明确不用转身。阶段目标变为真实逐帧走路/静态待机/普攻/技能、独立实体时钟与暂停、源像素与透明边缘、关键状态切换及相近漫画特效验证。旧纸片测试和资源仅保留在显式历史诊断，不作为当前正常角色表现。详见WISADEL-COMIC-2026-10-19.md；以下为历史计划，不能据此重新启用旧转身。

2026-10-17，用户要求将检查结论落实到项目，并先实施第一阶段。此计划针对当前正向斜俯视 2.5D Demo，不将视角改为横版侧视。

## 目标与边界

在实际游戏尺寸下，让起步、行走、停止和转向连贯、易读，逐步接近自然迈步。复用底层移动逻辑，各体型保留自己的表现方式。除用户本次明确要求 U01 减速外，保持路线、攻击、碰撞、部署和穿门规则；视觉过渡不能拖慢或推动逻辑实体。自动测试只能证明约束和回归，不能代替人类对自然程度的判断。

## 第一阶段反馈修正：半速、向下步态、转身（2026-10-17）

用户指出步频快、向下跛脚、转身缺动作，并确认实际移动与腿部动作均减半。本次 U01 的 moveSpeed=0.75、Stride=0.64，步周期约 0.853 秒（原约 0.427 秒）。向下走将纵深迈步投影缩为 35%，两脚统一落地基准，减少较短那条腿触及长度上限而反复截断的情况。

新增同角色右侧面与斜背面 PNG，保留源图和卡面；原正背面加新两方向，共四套定制裁片 Rig。转向状态约 0.38 秒，头先转、身体跟随、脚部做小幅交替换步，使用中间方向姿势；取消透明叠化。转身不暂停路线，镜像与姿态仅写视觉子节点。素材来源和原始提示词见 GENERATION-2026-10-17.md。

本轮仍不是完整专业分层素材：方向图间有造型差异，关节遮挡仍未补绘。第二阶段的正式部件、关键姿势和可复用视觉 Prefab 尚未完成。减速延长受塔攻击时间，未同步提高生命或削弱塔；当前 140 生命用于突破验证，默认 100 和低血量用于死亡验证。最新实际证据见 STATUS/QA。

## 当前检查结论

- 场景 `Assets/_Game/Scenes/InitialDemo.unity` 中的 `Monster U01/Series Sprite` 使用 `DemoSpriteVisual`；当前无怪物 Prefab、Animator、Animation Clip 或状态机。
- `DemoWalkPuppet` 把正背面整张 PNG 按硬编码多边形分区，运行时创建纸片关节；不是完整 Sprite Sheet，也没有独立身体部件和关节遮挡补图。旧两张跨步 PNG 未用于当前播放。
- `RouteMotion` 按累计距离沿固定 XZ 路线计算位置，`InitialDemo` 写逻辑根节点；表现只操作视觉子节点。不使用 Rigidbody 驱动移动。
- 主要问题依次为：完整图片缺少关节遮挡区域与侧面；转向原先最窄仅 28%；腿部求解可无限拉长；起步权重直接依赖整场时间、停止立即切回整图。现有资源不足以承诺商业级自然转身。
- 当前未安装 Unity 2D Animation。采用 A 的轻量过渡 + 现有分区试验；正式素材具备条件后再走 C。B 仅适用于将来确有连续动画帧的角色。

## 第一阶段：现有资源下的过渡修正（本次实施）

一个验收目标：U01 现有纸片步态的起停和转角更平顺，避免明显压扁与过度拉腿，并可运行回归。

1. 起停使用独立过渡状态，步相跟随实际距离；停止保留当前步相并回到站姿，重新起步重新过渡。整场暂停冻结动画，而非继续收脚。
2. 正背面短过渡，去除强烈压扁；保留图源不足造成的转面局限。
3. 限制腿部伸长，保持膝、踝和鞋连接；仅视觉子节点变化。
4. 在 Player 中采集走路、转角、起停证据。当前战斗没有途中站停机制，起停用独立美术预览验证，不新增战斗暂停/减速规则。
5. 验证暂停、重开、支撑脚、关节长度及现有突破/死亡/穿门结算，更新 Windows 试玩包。

状态：第一阶段实现与本机实机回归完成，观感待用户试玩。起停过渡约 0.18 秒，正背面约 0.16 秒淡化、视觉宽度保持 100%；腿部伸长最多 4%，踝部目标同时限制，缩短支撑行程以适应源图短腿。未新增图片、Animator、Prefab 或 Unity 包。

验证：34/34 Edit Mode、7/7 Play Mode，Windows 构建 0 错误，真实 Direct3D 12 Player 的突破/穿门单次结算/死亡/重开均通过。证据在 `artifacts/animation-phase1`，包括行走 32 帧、转角 48 帧、独立起停预览 66 帧。当前关卡没有途中站停，死亡和穿门仍立即隐藏实体；起停能力不代表新增了这些战斗动作。完整记录见 [QA](../QA.md)。

已观察限制：正背面淡化短暂重影；关节仍是源图裁片，没有遮挡补绘；纵深移动仍受双视图限制，不能保证所有方向支撑脚完全锁地。未运行完整鼠标流程、第二机离线或多单位性能测试。

## 第二阶段：真正可复用的角色素材样板（后续）

人类认可样板观感后，再用漂浮/无腿角色验证共享移动输入与独立表现。小型强调轻快，大型强调重量，多足按结构另做步序，不把双足模板强加给所有角色。不引入通用动画框架或重构战斗系统。
