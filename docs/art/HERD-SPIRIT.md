# 牧群灵体：冰蓝转化与倒下起身

2026-11-07，人类认可项目外V1原实体/灵体对照，并明确授权接入与补充倒下再起身。

## 当前表现与操作

从菜单进入“羁绊验证 → 牧群”，沿用原编队、库存和部署规则。全队符合牧群规则的非五费正常实体最终死亡后，原实体用自己的死亡帧倒下；0.7模拟秒后切换为同一角色的冰蓝灵体，用0.55模拟秒重新站起，然后沿原路线继续交战。头顶依次显示“凝聚”和“灵体”剩余时间。非人形保留自己的轮廓，不改成通用人形幽灵。

灵体以专用Shader将原有角色帧转为冰蓝半透明：保留明暗、细青色轮廓，腿脚透明度更高，脚边附少量程序网格散雾/微粒。没有重新生成各角色、替换原图或把概念对照图作为运行资源；原实体的颜色保持。旧实心接触阴影改为随灵体透明度淡出的极淡蓝色。

起身动作是复用原死亡动作可见前段的反向重组，**不是原游戏新增的骨骼复活动作**。人形可能是倒地或跪倒，非人形则表现为收拢后重新凝聚。取死亡动作前65%、最多0.65源秒，避免倒播末段消散尾帧；原倒下段适配到0.7模拟秒。当前没有额外音效。

## 模型与表现连接

`RemainingSynergies`为一次最终死亡记录只读`HerdSpiritState`，把原实体与新灵体的稳定ID关联，二者共用死亡时刻与`ReadyAt`。新实体通过现有`IsReviving/ReviveAt`门禁等待1.25模拟秒：期间不移动、不攻击、不占阻挡名额、不受伤或被守军选中，也不会让最后一张卡过早判负。10/12秒有效寿命从起身完成后开始；次数、倍率、攻击模式、穿门0与不再转化的规则保持。

`DemoSpriteVisual`在倒下结束时隐藏原尸体，在同处播放灵体重组，避免原尸体与新角色叠在一起。`HerdSpiritVisual`只读模拟/终局表现时钟，给原Sprite设置专用材质与逐实体PropertyBlock，驱动细边、透明度和散雾；不写路线或战斗属性。暂停冻结帧、透明度和散雾；死亡/到期消散0.45表现秒，重开随原角色视图清理。传送口在复起门禁期间也不推进实体位置。
