## 关键连接与配置入口

`DefenderTrialDefinition.rosterCards`引用3张既有小怪测试定义，`TacticalMapV3Tools.Apply`更新两图的连续高台与脚底高度，保留已有GUID和路线。编辑器菜单：Yesterday Convoy → Tactical Maps → Apply Approved V3；仅对该工具拥有的两图配置写入。

`BattleCardState`独立保存次数/下次可部署时刻；`ManualBattle.ConfigureCardLoadout`取得只读配置快照。控制器按拖中的卡调用同一部署事务，实体保留卡、路线和蓝门身份；旧单卡/游击队继续使用旧兼容入口。`UnitCombat`为技能、伤害和动画提供实体自己的配置。

`DefenderRosterView`读取已发射攻击的目标快照选择朝向，`DefenderArt`读取正背面图集；怪物显示按自己的CardDefinition绑定，`EngagementView`按攻击来源选择近战/弹道/破甲表现。所有战斗与动作仍读取同一模拟时钟。主场景文件、Prefab、Packages、ProjectSettings未改；不创建ZIP/Releases。
