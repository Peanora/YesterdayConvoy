## 三星阶段与本作适配值（代码绑定待验）

一、二星保持单阶段，生命归零播放原 `Die`，不会自动复起。Campaign仅在塔露拉三星时开启 `TalulahSecondPhase`；独立三星样板可显式启用该试验配置，不改旧单怪测试。

| 时点/阶段 | 期望行为 |
| --- | --- |
| A首次生命归零 | HP0但仍为Active；原地倒下5秒，暂不触发最终死亡羁绊/结算 |
| 首次自动雨 | 28秒状态、10波、2秒间隔；首波相对状态开始+2秒是本作适配值，原资料没有确证该首波偏移 |
| B复现 | 最大生命和生命为A最大生命的150%，攻击预算150%；复现后15秒无敌，最初2.766667秒完整起身锁包含其中 |
| B普通战斗 | 起身后可移动、普攻、积攒SP和手动六秒火雨 |
| B生命归零 | 仍Active，倒下5秒后进入28秒最终自动雨；原倒下片长5.333333秒，最后0.333333秒与雨初期重叠播放，不截尾 |
| 最终自动雨结束 | 才执行一次最终死亡/羁绊回调；原最终收束1.233333秒播完后允许清视图与显示结算 |

自动雨拥有独立波数/时钟，不消耗SP或手动弹药、不增加手动施放次数；根据当前形态攻击预算，通过既有伤害入口结算法术伤害。过渡与起身锁内不回SP、不能手动施法；致死取消未结算弹道及剩余手动波次，已结算伤害不回滚。

手动和自动都使用已确认的橙色可穿透火浪，按实际保存地面/高台实时投影覆盖，不恢复此前被否定的尖头火球。自动视觉仅10波、2秒间隔，不把六秒循环机械扩展成三十多排。朝向统一按相机投影与实际控制方向处理，诱导先于恐惧；阶段锁与暂停保持方向，未旋转逻辑根节点。
