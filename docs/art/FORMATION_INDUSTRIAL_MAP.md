## 当前依据与覆盖范围

2026-11-17，用户确认新的暖灰工业棋盘概念图并要求接入。**本节是当前美术与地形依据，覆盖下方历史原材质棋盘方案。** 同日最新试玩反馈将保存棋盘扩大为20×8，左侧战前部署区由6×8扩大为12×8，左右使用独立可见的固定视图，中央采用偏暖灰、细颗粒、低反光旧混凝土；通过窄格缝、倒角与轻微磨边读格，不再使用强明暗棋盘、道路白短线和米金光泽。厂房、服务带、侧墙、栏杆与脚手架围合场地，完整透明红蓝门逐格相邻，原 A 商店与既定战斗核心保留。

概念图是AI生成的材质、构图和地形关系预览，实际Unity画面仍可能有差异；它不是已经验收的实机截图，也不作为整张地板贴图导入。本轮以保存场景的实际渲染、Player和人类试玩画面核对结果验收，不通过再次宣称“原作同款”替代对照。

当前棋盘底座、后部平台、横向边框／栏杆／管线按左右接缝拆成独立保存对象，使固定视图不会露出另一侧的空底座；远处工业服务地面与原背景仍共享。

## 固定的左右独立视图

整备默认只显示左侧12×8部署区及红门；V键或顶部按钮切换到右侧守军视图，开战切至右侧，重试和下一关整备返回左侧。两套取景位置在初始化时根据保存的地图尺寸与大体型角色预留高度确定，切换直接完成；购买、拖动、角色待机、战斗移动和死亡不重新调整取景，也不平移追踪或缩放。俯角60°、FOV40、零偏航与零滚转保留，原A商店的模型平台相机独立运行。

表现层将本场静态地砖、门、右侧地形和局部外围按分区分层显示，并按角色逻辑位置显示对应一侧的动态本体和标识；跨度较大的工业背景保留共享。左右在玩家视野中分开，底层仍使用同一保存场景和连续战斗坐标，原部署格出生／复活与进蓝门规则保持。不会因侦察切换重建地形、重抽敌阵或推进模拟时间。

工业外围随20格宽度扩展，底格160个、外围台边56个均保存。六处遮挡原左下部署格的高前景沿用向外移动1.8单位的保存调整；布阵可见性须以当前固定左视图的实机画面复核，作者工具的整图预览不代替玩家视角验收。

### 已保存场景与编辑工具

场景为 `Assets/Scenes/FormationBattle.unity`，静态环境根名为 `LS5 native formation courtyard`。112 个 `Tile col,row` 对象在编辑模式中可查看、选择和保存，引用原 LS-5 持久 Mesh；地砖局部顶面约 y=-.0200154，保存对象以相应高度补偿对齐逻辑地面。外围、远景与 16 个原门同样保存于场景，Play 仅创建动态角色、界面与战斗反馈，不在运行时重建整图。

相机保留 LS-5 的 **60° 俯角、FOV40、偏航／翻滚为 0 的轻透视方向**，使用完整相机视口，再按本作 14×8 棋盘和原 A 界面留出的中部战场区域调整距离／偏移。当前工具的目标框为虚拟 1280×720 坐标中的 `(200,108,792,365)`；它是本次 UI 适配框，不宣称等于原 LS-5 的地图尺寸或相机距离。先前绘制方案的约 38.86°／FOV4.95 与 1280×500 压缩背景不再适用。
