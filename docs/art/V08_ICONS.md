# v0.8 原创界面图标

来源：本轮程序新绘几何图形，没有使用第三方图片或字体。

- `merchant`：行商钱袋；`armory`：军械库弹药；`painted-world`：画中天地画框山形；`steam`：蒸汽骑士面罩与蒸汽。
- `v08-crown`、`v08-shield`、`v08-cloak`：三种人口装备，分别使用金、蓝、赤色。
- 可编辑源：`source-records/v08-ui-icons/*.svg`。运行：`python tools/generate_v08_icons.py`，从同一几何定义输出SVG及4倍超采样、256×256透明PNG；脚本再次运行保留既有GUID。
