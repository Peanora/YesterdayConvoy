# 泥岩与留声机独立试玩

三个留声机对象保存在场景，可编辑位置/初始控制/范围。进攻方为红、守军为蓝、中立为灰；蓝色进度表示守军夺回进度。相邻守军每人每秒+1，满100转为守军控制；普通怪不自动得到原作没有的近邻占领能力。泥岩占据将控制归零并夺取。装置每1.5秒攻击范围内最大生命最高的对方，每次5%目标最大生命法伤；每5秒治疗范围内生命比例最低的友方10%最大生命，0.55秒后结算。中立不攻击/治疗；归属改变时取消原阵营未命中的效果。数值仍是试玩参数，非正式平衡。
