# 感染形态与爆裂反馈

2026-11-06人类采用外部V1三选一界面和爆裂反馈看稿，授权UI、只读命中结果与表现接入；不修改羁绊数值或固有自爆。

## 操作与实际规则

整备时首次达到感染2/4/6档会自动打开选择面板；移出编队或出售造成降档后，重新达到高档会再次弹出，例如6→4→6。初始感染专项6档也自动打开。同档人数变化、刷新或切换形态不重复弹；普通换关保留当前档位，新挑战重新判定。随时仍可点左侧“感染生物”行手动查看。

选择集群、甲壳或爆裂主形态；6档可再选一种不同的2档副形态。低档明确显示副形态未解锁。选择后窗口保持，点击完成、关闭或外侧返回；开战锁定，战斗中只读。原构筑/运营按钮也会打开同一面板，不再靠隐藏文字轮换。

普通挑战默认集群主/甲壳副，独立感染专项默认爆裂主/甲壳副。选择不是本轮新加的玩法，主要修复可发现性与“低档副形态好像生效”的误导。

2/4/6档、爆裂35/65/85法伤、每星+35%、半径1/1.2/1.3、最多2/3/3人、最终死亡后0.2秒保持。集群与甲壳保持既有逻辑；原自爆虫的物理/寒冷爆炸独立，复起首倒和分体不重复复制羁绊爆裂。

## 连接

- `InfectionFormUI`复用`SetCampaignForms`及战前快照事务，`SynergySidebar`显示主副和入口。模态区域按当前面板命中，拦截地图/商店拖动，Escape或点外侧可关闭；其他羁绊详情保持。
- `SyncShopDeck`成功刷新后比较感染当前档位与上一次档位，`RefreshInfectionChoicePrompt`只在上升跨档时打开面板，不记录永久已选/历史最高。`StartCampaign`重置观察值；形态变更同档不重弹。外点判定使用`DrawLoopInterface`在GUI矩阵前已换算的逻辑点，避免大窗口左列再次缩放成窗外点击。
- `AdvancedSynergies.InfectionBurst`保存源实体/卡牌及原选中目标的只读`Hits`。每条含实体、命中位置、实际扣血；`TotalDamage`为真实扣血之和，包括致死截断，不以面板预算或显示层附近单位替代。
- `CommonCombatVfxDirector`仍独占已接入的`common/common_firemagic_hit_01`，按真实直径显式适配；`OriginalCombatVfxLayer`旧调用继续scale1，防止池复用时其他角色变大。
- `InfectionBurstFeedback`画死亡0.2秒预告薄圈、原点冲击及已记录目标的小标记，显示短“感染爆裂·命中N”；原通用伤害跳字仍独占数值，不重复显示假伤害。原火27帧/0.9秒，标签最多1.2秒；显式进入原结算表现尾，暂停/倍速/终局停钟和重开清理同步。
