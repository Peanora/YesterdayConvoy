# 26位首领机制接入记录（2026-11-11）

2026-11-12修订：已接入怪物技能全部自动触发。以下为机制接入历史与伤害连接；其中手动SP／点击施放叙述由用户最新自动规则覆盖。原始CD、攻击／自然SP、血量／形态条件和适配见 [自动技能合同](AUTOMATIC_MONSTER_SKILLS.md)。塔露拉与冬痕不重复施放旧手动派生能力，维维美装备技能会自行判断施放，圣徒的地／飞返回按真实致命输入且各最多2次。

本轮保留7个既有核心的 CardId 与原构筑入口，新增19种可部署卡。此文件说明运行规则和适配边界；实际 Unity 测试、Player 与构建结果由本轮 QA 记录填写，静态编译不代表实机通过。

## 运行连接

`BossRosterCatalog` 保存19张新卡的试验基础数值。`BossRosterRules` 保存外部已审核的源动作片长、OnAttack 与技能元数据；运行状态由每个实体的 `BossRosterState` 独立持有。`ManualBattle` 的 `BossRosterCombat / Mechanics / Environment` partial 直接操作本场单位、干员生命、技力、阻挡、路线和对象。没有嵌浏览器或以展厅按钮代替战斗。

原有 `CARD_M25 / CARD_M32 / CARD_TALULAH_TRIAL / CARD_M20 / CARD_M14 / CARD_M28 / CARD_WISADEL_APRIL` 不进入新19的状态机。`BossCoreExtensions` 只补塔露拉、冬痕霜星、维维美已经审出的缺口。既有梅菲斯特、蔓德拉、爱国者、泥岩技能入口继续使用原实现。

所有时间来自 `ManualBattle.Clock`。暂停冻结施法、命中、飞行、对象、技力、复起与阶段；重开清空对象、事件、待结算、状态和请求记录，并保留准备阶段选定的维维美技能及 TL 关卡模板。定点攻击在起手前没有合法目标时拒绝且不扣 SP/次数；已经起手后保留完整动作锁。纯增益、召唤或铺场可空开。请求去重按本场、请求号、实体与技能区分。

`BossRosterEvents` 只记录真实事实，包含独立 ActivationId、阶段、区域、命中序号和实际结算结果。FX 不提供命中判断或伤害。命中确认同时考虑生命损失、欠血/代偿等已实现防守机制；纯视觉不能把目标存在当命中。

普通远程在源OnAttack时生成真实弹道事件，按原投射物速度推进到有限Impact时刻后才扣血：W为5、圣愚为8，其余本轮普通远程为10。近战接触不添加飞行。所有已接普通弹道的原 `_stopWhenSourceInvalid=0`，因此已经发射的弹道在施法者死亡后继续结算；未发射的接触和未来施法则中断。发射时记录阶段/区域，避免飞行中转阶段把旧弹误播成新形态。当前本作沿既有 `CombatShot` 规则记录发射目标位置，不宣称复刻原客户端完整追踪/抛物线运动器。

## 旧核心补缺

- **塔露拉**：原有两阶段/火雨保留。普攻直接走真实伤害入口并施加灼息，避免先减伤后补差造成重复伤害。灼息30.5秒，持续伤害在30秒内递增，刷新保留递增进度；只有这名实际灼息干员造成的伤害减半，环境伤害没有虚构来源。周期点燃与引爆/十字传播、第二形态召唤能量聚合体直接影响本场生命。
- **冬痕霜星**：保留原冻封、冰环、暴风雪与5秒复起强度。原复起动作7.2秒映射到本作5秒窗口；原作复起规则为10秒，此差异明确保留。增加复起后20秒保护、普通攻击寒冷5秒、冰环寒冷10秒/冻结增伤/二阶段扩圈、黑冰封地及独立源石冰晶寒潮。封地确证为IceShield/IceShield[Reborn]→Skill_1；普通冰环确证为IceBurst（Attack）/IceBurst[Reborn]（Skill_3），两个能力独立记录，不能互借动作。冰环保留本作原即时伤害与3秒动作窗口，完整源片长按该窗口映射，不宣称已重写为原客户端延迟结算。
- **维维美**：准备阶段只装备S1/S2/S3之一，默认旧S3六发机制。S1用攻击回复2SP、强化下一次合法攻击并增加余震/晕眩；S2初始15/消耗25SP、持续25秒，前半三目标、后半四连发，可在攻击动作结束后关闭；S3继续原成功入口与弹药，增补魂灵和常驻效果的真实开始/结束。普通攻击补余震/残影；派生伤害不再次当普通命中处理。

魂灵是独立可受伤实体，最多3个，赋予本体近身迷彩。它不进行普攻；原 `sktok_wisdel_wward` 自动技能需要5SP、随机返0/1/2SP、优先未标记目标、法术伤害/减速/残影。原超新星魂灵Attack长2.0333333秒，OnAttack在0.0333333秒，原弹道速度15；时点由真实战斗记录提供给模型与FX。源生命/防御及本作父单位比例数值分开记录。

## 明确的场地与调度适配

1. 原作角色的关卡机关位置/波次不等于本作固定路线。卡德霍原本的猎犬和痛楚由原关卡产生，本轮由此实体代管有限4猎犬、3痛楚波次：猎犬全死后1秒间隔依次出现。痛楚有原3秒出生保护；感官共生加攻、5.2秒Blink回血/位移/原End收手、25秒痛吼等直接作用真实战斗。不是定时删除猎犬或三个按钮假扮阶段。原地图的完整波次和检查点未移入本作。
2. 瓦列里奥原基质来自原地图；本作为每次部署携带有限4个分批来流，耗尽不无限生成。默认挑战也能产生真实超限反制闭环，不新增DP消耗。`ConfigureBossRosterMatrixFeed(false)` 可在准备阶段关闭这项供给，用于源条件验证。
3. 源石冰晶、能量聚合体等位置取当前已保存路线点及现有单位位置，未声称复刻原关卡布局；黑冰只能选择当前地图已有干员地块，不运行时重建整张地图。完整原调谐节奏、昔日道标的敌友预设波次、封印整张源场地、摄影机朝向的无限摄影光等属于地图依赖，本轮采用有限覆盖/区域推进适配，不能称为完整原场景移植。没有Move动作的源Boss以待机姿势沿本作战术路线平移，这只是路线适配，不能称为原作完整行走；岁默认采用已确认可见的Skill_Idle_A/B，透明Idle等待帧不作为正常待机。
4. 猎犬proto已按原jump图补近战与附着：普通近身法伤使用原1.8秒间隔/0.6667秒接触；首次就绪15秒，原Skill_Begin 0.1667秒→目标处透明Skill_Loop，持续10秒每秒真实法伤→Skill_End 0.3333秒回原位置，结束后CD40秒。每次咬击给予1.5秒物/法命中率降至20%的不叠加减益；同一守军弹丸只判定一次命中，真伤不判命中。技能图有原控制免疫，普通猎犬没有被泛化成免控；目标或自身死亡退链，自身死亡不会把尸体传回原位。逐秒首次tick采用满1秒的明确本作调度；没有声称取得原客户端首tick代码。四只辅助体的近身移动/接触由对象战斗实现，不是通用speed5远程弹道。

狂躁是独立窄状态，没有拿灼燃替代；原阈值、爆发和能力触发规则见[元素机制](https://prts.wiki/w/元素)。原守军干员规则为1000累计，15秒攻击速度+50，每秒100真伤、每次攻击/技能启动再+50、上限600；本作与现有元素环一致按/10归一为100累计和10/+5/60真伤，时间不变，普通命中及附着均附加0.3×本作猎犬攻击的累计值。猎犬攻击按原280/本体900比例映射本作攻击。攻击/技能启动观察实际能力事实，每枚弹丸/多目标命中不重复加层；伤害无来源，避免灼息来源减伤错误生效。当前守军按本作DefenderSettings角色类处理；中立/明确元素免疫关卡可通过准备阶段只读ConfigureBossRosterRampageImmunity提供免疫ID，不按Boss身份凭空免疫。原技能首tick及全部客户端免疫派发未取得通用源码的部分仍按此明确适配。

5. 易的守军明晦在本轮固定关卡中以稳定实体ID分配，避免运行时 `GetHashCode` 随机改变；原作按地图明确配置明晦的布局没有直接复制。
