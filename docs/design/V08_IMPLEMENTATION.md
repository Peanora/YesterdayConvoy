# v0.8 数值与羁绊实施说明

本轮依据 [用户确认的评审稿](V08_REVIEW.md) 实施；用户另确认由程序补齐蒸汽骑士可调初版。输入为 main c4e39490，加上本机已验证的 Direct3D 11 战斗崩溃修复。旧 v0.7 参数与模型报告保留为历史，不代表新版表现。

## 已采用规则

- 九条三星五费路线：八名原生五费及五费塔露拉。生命倍率18、攻击倍率10、额外护甲50、法抗30且最终不超过80；首次开战满SP，免眩晕、冻结、束缚、沉默与强制位移。减攻速、属性削弱与伤害仍按常规结算。模式复活不重发开场满SP。
- 五费塔露拉一二星为6×200%法伤、8×40%法术灼烧，一星生命2800。三星变为全敌6×2500%攻击真伤、保留40%灼烧，首次施法免伤。三四费及锁费强化沿用原值。
- 三星维维美S1为12×1500%真伤，S2全体1000%真伤普攻8秒，S3为12×2000%全场真伤，发射间隔0.7秒、弹药8.4秒。三星万火、炉芯、岁为20000%真伤，岁随后每4秒5000%真伤。其它三星辅助、爱国者转段和唤回按评审稿。
- 阵营档位为整合3/5/7/9、雪怪2/4/6、泥岩2/3/5、深池2/4/7、萨卡兹2/4/6/10、海嗣2/4/6、伊比利亚2/4、蒸汽1/2/3。最高档均比天然人数多2人。固定岁影、国度与三个专属羁绊不进徽章匣。
- 伊比利亚与蒸汽徽章仅进入徽章匣，不占宝石＋基础件的既有配方；可转职集合共17种，徽章匣从真实集合采样。
- 雪怪全敌寒风用战斗时钟：第2秒、之后每8秒一次寒冷，需另一次寒冷才能冻结。深池7档是唯一命名的永恒灼烧，锁定敌人入场最大生命，每秒1%真伤、受治疗减半，覆盖增援。萨卡兹10档全队生命和攻击增幅进入加法区，取消两契代价。
- 泥岩4人经验上限79，5人才可到99。巨像V另需80经验、天然星级和9及等级9；V新增生命150%、攻击100%、每8秒全队20%最大生命护盾。海嗣6档在原溟痕上追加初始部署格与确定性最短合法路径，不随移动铺满。

## 战前界面

从顶部“搭档”进入“军阵抉择”：新增伊比利亚本场誓约、行商军需、画中天地中心、蒸汽主驾驶与人口来源。

- 伊比利亚2档选择一项，4档选两项不同项；默认赎罪、再激活狂信，可在整备重选，开战锁定。审判仅由友方本体原生直接伤害触发，普通12%、精英/首领5%，严格低于阈值；DOT与召唤物不触发。
- 行商每位面支付8金币换基础件、8XP或4次刷新一次，次数记录在本局，重试/出售不刷新。迁入标签的原被动不另发一份。
- 军械库首次选定免费，此后每场整备再免费切换一次。画境中心用行列选择，只能选我方合法部署格；未选择时用岁原始部署格。显现半径3内本体减伤10%。
- 角色详情显示三星五费独立面板；蒸汽成员另有四格“机甲模块”栏，不占三件普通装备。

## 蒸汽骑士初版参数与边界

驾驶员为4费、蒸汽／爆破、生命1600、攻击230、护甲36、法抗25、攻距1.2、间隔2.2秒、移速0.6、自然SP8/24、动作1.1秒。

单台机甲按驾驶员最终面板合体：生命和×1.6，攻击最高值＋其余之和×0.5，甲抗取最高值。普通行动为重拳；主技3段各120%物伤。2档高压护甲另加30护甲、20法抗；3档机甲生命与攻击各再加100%，并追加3段各180%全场法伤肩炮。3档同时解锁过载炉芯和肩炮模块。

主驾驶可选，默认第一名蒸汽成员。只继承其普通装备触发、攻速、能力强度和技力属性。其它驾驶员的装备只通过各自最终面板参与合体公式；不再将装备、三星和全队加成乘一遍。驾驶员标签保留计数，机甲对同名标签合并为一份。隐藏驾驶员不接受选敌、治疗、独立复活，不生成死亡／产金／接棒事件。机甲是一个真正可被攻击、8秒完整复活、实际进门判胜的本体；主C指向隐藏驾驶员时重定向至机甲。天然身份专属触发不复制给机甲；隐藏驾驶员的原生技能和被动暂停，固定双人关系仍保留人数但不代替驾驶员施法。

**美术边界：**本轮驾驶员与机甲复用仓库已有 `MonsterCombatArt/GOLEM` 的巨像卡面与动作，界面明确为“原型机”。这是可操作规则原型，未声称已完成蒸汽骑士原作模型或原版特效；没有新增下载或复制原作媒体。替换专用美术时保持 `CARD_STEAM` 身份与配置接口。

## 冠冕与持久收益

赤＋赤＝冠冕，蓝＋蓝＝护盾，赤＋蓝＝披风；玩家主动合成，每件提供人口1，物品栏与装备都计入，只计一次。普通进阶随机池仍为21件，不包含三种人口装备。实际人口 `min(14, 等级 + 无人落伍额外人口 + 冠冕类件数)`，商店等级仍最高10。

同一角色同时穿三种不同冠冕首次获得300金币；本局永久解锁后续唯一新节点100金币，拆装、重试和停留均不重复发。坎诺特三星300金币与新节点100金币另有独立去重键，替换旧120／30。

## 实现口径与保留项

- 最大生命光环变化保留当前生命比例；护盾总量仍受80%最大生命上限约束。
- 圣徒附伤对每名受益者的每次主技最多12个原生伤害段，范围人数不增加段数；普攻每个原生段只附一次，附伤不递归。每人每场第一次致命伤回满血，优先于原生复起和模式死亡。
- 后续候选“整合之火／薪火”和“终幕指挥／首席”本轮不采用。
- 不改基础收入、经验表、费用概率、库存或棋盘布局。保存场景只追加驾驶员卡引用。
- 数值源快照是 `parameters.v0.8.json`，生成器默认读取新版；星级、生命周期及战斗事件分别在 `FormationStarRules`、`FormationCampaignV08`、`FormationCombatV08` 中实现。参数说明不等于真实通关率结论；验收以 QA 的实际结果为准。
