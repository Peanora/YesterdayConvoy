# 棋盘守军难度与阵型

2026-11-19，适用正式棋盘与难度试玩。此页修订 v0.7 的守军名单、落位、关卡面板和遭遇倍率。节点顺序、补给、奖励、经济、进门与复活规则沿用原设计。

## 位面难度

《货币战争》把低压奖励、普通和精英组成的常规战、可选档位遭遇、位面末首领放在一条路线中。《昨日圆车》以此安排阵容检查，守军生命与攻击按本作的限时、复活与进门成本设定。[《货币战争》4.7 客户端教学](https://hsr.gachabase.net/tutorials/currency-wars/100036/planes-and-nodes/release?lang=chs)

| 节点 | 阵容目标 |
| --- | --- |
| 1-1、1-2 | 起手三人有资源过渡。前两战奖励可跨关领取。 |
| 1-3 | 正式战备后的首次检查。三人口可以靠配装、站位和一名二星过关，四人口也可用新增单位补火力。 |
| 1-4 | 芙蓉保护米格鲁，开始要求升星、装备或有效羁绊。原样停留在三名一星的队伍应能感到压力。 |
| 1-6 | 余第一次登场，保护双重装和集中后排。五人口配低费二星是常规路线，高质量四人仍可突破。 |
| 1-9 | 斩业星熊压第一接敌点。用成型前排和一个有输出装备的核心打穿第一位面。 |
| 2-4、2-7 | 检验二星前排、主副输出及续航。Mon3tr 和塞雷娅分别代表转形与治疗阵。 |
| 3-4、3-7 | 检验成型阵容的输出、持续能力及应对多段伤害的站位。 |

三次遭遇共享各自的阵容与站位，时限均为 90 秒。四档生命依次为 **1、1.7、3、5.5 倍**，攻击为 **1、1.08、1.18、1.30 倍**。奖励仍按削减进度严格大于 25% 发放。实际强度和测试口径见 [QA](../QA.md)。

## 固定职责槽位

守军先取逐关名单，再按种子选择北侧或南侧。前排占靠红门的低地，后排优先占高台。最多九名守军落在同一处不超过五列、四行的区域。Mon3tr 的重构点和望的棋子格提前留空并经过同一地形检查。同关重试和切换遭遇档位保持阵容与坐标。

| 防线 | 前排格，按入列顺序 | 后排格，按入列顺序 |
| --- | --- | --- |
| 北侧 | (17,2)、(17,3)、(17,1)、(18,2) | (19,2)、(19,1)、(20,2)、(20,1)、(20,3) |
| 南侧 | (18,5)、(18,6)、(18,7)、(19,5) | (20,5)、(20,6)、(21,5)、(21,6)、(21,7) |
