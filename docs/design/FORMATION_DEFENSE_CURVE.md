# 棋盘守军难度与阵型

适用正式棋盘与难度试玩。此页记录现役关卡的守军名单、落位、面板和遭遇倍率。2026-11-22 试玩回修将奖励关守军设为 1 点生命，把普通守军分散到两翼，并从 1-3 起加强过渡战。3-7 仍由圣聆初雪单独守关，使用两阶段面板。

## 位面难度

《货币战争》把低压奖励、普通和精英组成的常规战、可选档位遭遇、位面末首领放在一条路线中。《昨日圆车》以此安排阵容检查，守军生命与攻击按本作的限时、复活与进门成本设定。[《货币战争》4.7 客户端教学](https://hsr.gachabase.net/tutorials/currency-wars/100036/planes-and-nodes/release?lang=chs)

| 节点 | 阵容目标 |
| --- | --- |
| 1-1、1-2 | 起手三人有资源过渡。奖励守军均有 1 点生命，掉落可以跨关领取。 |
| 1-3 | 正式战备后的首次检查。三人口可以靠配装、站位和一名二星过关，四人口也可用新增单位补火力。 |
| 1-4 | 芙蓉支援当地守军，开始要求升星、装备或有效羁绊。原样停留在三名一星的队伍应能感到压力。 |
| 1-6 | 余第一次登场，防线分为两翼。目标是让五人口配低费二星常规突破，优质四人阵容也有机会。 |
| 1-9 | 斩业星熊压第一接敌点。用成型前排和一个有输出装备的核心打穿第一位面。 |
| 2-4、2-7 | 检验二星前排、主副输出及续航。Mon3tr 和塞雷娅分别代表转形与治疗阵。 |
| 3-4、3-5 | 检验成型阵容的输出、续航及应对直线伤害的站位。3-5 先用一档阵容提供接近终局的火力检查。 |
| 3-7 | 让成型阵容攻破圣聆初雪的两段生命，应对扩散积雪、全场冻结及二阶段范围伤害，并留出进门时间。 |

三次遭遇共享各自的阵容与站位，时限均为 90 秒。四档生命依次为 **1、1.7、3、5.5 倍**，攻击为 **1、1.08、1.18、1.30 倍**。奖励仍按削减进度严格大于 25% 发放。实际强度和测试口径见 [QA](../QA.md)。

## 固定职责槽位

除固定在中路的圣聆初雪首领战外，守军取逐关名单，种子决定哪翼先排。前、后排分别在两翼交替占用各自地图已保存的格点。前排使用低地，后排先安排狙击或术师，再排支援岗位。每翼首位常规后排远程覆盖从首位前排向红门方向 3.5 格的接敌点，实际射程依据两者的地图距离取值。首两次常规战 1-3、1-4 的补充射程上限为 4.25 格，给开局阵容留出接敌空间。奖励关沿用普通射程。Mon3tr 的重构点和望的棋子格跟各自翼一起保留。同关重试和切换遭遇档位保持阵容与坐标。
