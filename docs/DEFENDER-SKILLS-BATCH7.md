## 固定路线试玩适配边界

- 试玩基础攻防血量为本作参数。陈的原减防200映射减防20；侵蚀原1000/2000阈值映射100/200，5000元素伤害映射500，永久减防120映射12，8秒爆发冷却保留。普通/精英使用普通阈值，已实现的首领标记使用首领阈值。永久减防可叠；陈粘液减防不叠。
- 原作格形范围用本作配置的径向范围表示，火陈每次攻击覆盖当次整个技能范围并持续5秒；地面移速×0.6。克莱门莎爆发额外打击保留中心及上下左右四格的十字形范围。
- 安洁莉娜起飞期间不阻挡地面、不被地面单位直接索敌，可阻挡2个合法可阻挡空中单位。仅在未阻挡、未被控制及攻击动作结束时，向技能范围内未被阻挡的合法空中单位移动；不引入新寻路。范围内空中移速×0.6，空中来源普通伤害×0.4。
- 凯尔希优先向敌人发射，否则选择需治疗的友军；医疗单元追踪存活目标落点，伤害和治疗半径均1.5且可对空。选敌时先伤害并停顿5秒、0.4秒后治疗；选友时先治疗、0.4秒后伤害且不附加停顿。此0.4秒来自原次级医疗弹生命周期。已释放的医疗单元与已触发侵蚀使用发射快照完成落点；起手未释放时来源死亡不产生命中。普通医疗沿用既有真实治疗队列。
- 当前伤害模型只有物理/法术与真实伤害旁路。侵蚀的元素分量以独立标记的旁路伤害结算；没有伪称实现原作完整元素抗性体系。其他角色尚未实现的侵蚀来源不会凭空制造全场侵蚀事件。
- 弹药技能用模型内部的大持续上限等待真实弹药耗尽，不按固定计时制造攻击或侵蚀爆发。头顶条、商店战场条与详情面板均显示真实剩余弹药，耗尽时显示收招，不展示该内部时间上限。安洁莉娜状态直接读取模型的阻空2/阻地0容量。技能由守军现有AI自然开启，正式关卡数据不变。

## 数据流与呈现合同

`DefenderSkillTrials` 正常角色入口 → `DefenderTrials/D32…D35` → 不可变 `DefenderSettings` → 独立 `DefenderState` → `SeventhDefenderSkills` 产生真实攻击/治疗及有界呈现日志。

每个真实守军攻击/治疗 `CombatShot` 在排队时保存 `DefenderActionStartedAt/DefenderActionRate`，后续攻速或动作改变不会改写；独立浮游炮攻击保存自己的发射动作时间。医疗延时还保存发射时攻击力，避免落点误读后续状态。`SeventhSecondary` 区分医疗范围结算与侵蚀追加结算，呈现层可以避免对每个受击者重复播放发射。

只读 `SeventhDefenderEvents` 最多256条，字段为 `Kind/SourceId/TargetId/At/EndsAt/Position/Direction/RunId/Sequence`；种类为 `SkillStart/SkillEnd/StickyGround/FlightIntercept/CorrosionBurst/MedicalDetonation/HealingPulse`。日志仅供特效消费，不能作为第二伤害源。`HealingPulse.At` 为原动作释放医疗单元的时刻（动作开始后8/15秒），`EndsAt` 为预计到达时刻；呈现层须等待 At，不把起手当已飞行；`MedicalDetonation` 仅在真实落点结算时写入。粘液日志为真实攻击所生成的持续区域，`At` 前不生效。重开清空队列、状态与序号，以新的 RunId 隔离旧记录。

原有六星附带呈现修正：D24真实召来预备守军才更新 `LastReinforcementAt`；D23真实获得技能自疗才更新 `LastSelfSkillHealAt`；D27雪格真实生成或从零层重新长起时记录 `Time`。这些记录不改变原伤害、治疗量、层数或次数。另按原D24 Skill_3_Skill动作，将其默认S3起手从0.7秒对齐为1.6秒；弹药和伤害不变，对应五连发测试改为等待完整起手。

## 原特效实际绑定

- D32 普攻/S3的原startEvent2层从不可变动作开始时刻播放，event4层从真实释放时刻播放；原SwitchableBackEffect的`_b`仅作背向替换。持续buff随真技能状态，范围粘液随真实攻击产生的StickyGround与5秒期限，命中特效随真实应用的攻击。
- D33 原普攻/S3发射与命中、技能武器/左右替代层、真实移动时飞行尾迹均已接入。范围线使用原LineRenderer单边、材质/宽度/UV，沿本作真实径向范围离散成32边适配；没有把原编辑器XY的13点图形硬贴地面。原独立Combat动作的FSM入口未被序列化证据确认，保留资源并登记未绑定，不以背向或首击猜触发。
- D34 技能range确为原PassiveBuffAbility的全程caster层，真实结束播放range_end；原Mark_all仅由实际CorrosionBurst触发。普通/S3方向层择一；范围追加结算不重播caster/projectile。
- D35 普通医疗原start/trail/hit齐全。S2按原模板`dmg→sub_heal`、`heal→sub_dmg`链绑定反直觉命名的indicator与delayed range。医疗施放/弹道消费实际释放记录；落点消费真实MedicalDetonation，范围结算不会再次发射。
- D23普通治疗保留原attack_start/trail/hit，缺少的原line01不拿S3层替代；原S3 line02仅供真实S3治疗shot的实际端点，绝不为自疗制造新shot或假端点。自疗使用真实获得生命时刻与位置。D24本模型成功召唤即落地，只接真实落点range/ground，没有在落地后假飞0.7秒。D26技能range从每次真实攻击释放并按真实delta校准方向，非恒定光环。D26武器Trail经原骨轨迹采样仍为空，保持明确缺口；D30 default AnimAttack有NeverTrigger，原buff04仅预加载，不假造普通攻击。
