# 军团攻擂：维什戴尔 · 超新星

2026-11-10，独立玩法样板。用户本轮明确指定放大的维什戴尔皮肤、紧凑地图、Boss血条、半血爆裂黎明加速、整队免费登场以及阵亡后的长再部署时间；本页覆盖此独立模式的旧DP、次数和穿门胜利规则。正式十二节点行动和其他试玩沿各自规则。

## 入口与操作

- 打开 `Builds/Windows/YesterdayConvoy.exe`，系统菜单选择“军团攻擂 · 维什戴尔”；角色测试页也有同名入口。
- 独立场景 `Assets/Scenes/WisadelBossArena.unity`。地形为编辑模式已保存的9×7模块棋盘，八处不重叠集结位置；Play不搭建整张地图。
- 开场是无限金币、真实分费用有限牌库的自由整备。初始8级、八张二星整合成员；可以购买、升星、换编队和调整已有羁绊选择。
- 点击“整队出击”，全部编队成员同时登场。正常成员在场时不能重复部署；最终阵亡后开始90模拟秒冷却，原角色复起期间仍算在场。
- 到时点击底部就绪卡牌，或“整队再部署”。重新登场是新实体，生命和实体技能重新初始化；召唤物和支援体不占独立编队部署卡。
- 本模式不扣DP、不扣原部署次数；不保留原45秒等入场CD。90秒只从最终阵亡后开始，暂停冻结，1×/2×共享战斗模拟时钟。暂停时可部署已就绪成员，仍不推进战斗。
- 点击场上角色使用已有手动技能。全灭不会直接判负，Boss损失生命保留；本样板不设倒计时判负，可以继续等待再部署。
- “整备”返回当前编队的准备阶段，保留已调整的收藏和星级，重置Boss及战斗。击败Boss后也可返回整备。

## 数据与运行连接

`Assets/Data/Resources/BossArena/WisadelArena.asset` 保存再部署时间、加速倍率及显示尺寸，引用 `Preparation.asset` 和 `Encounter.asset`。后者保存真实Boss血攻、原动作时序、八条固定接敌路线。修改这些Inspector值后重进场景生效，不会由Author工具覆盖人工值。

`BossArenaBootstrap` 绑定独立模式并复用现有自由整备；`CampaignV2Balance` 提供正式逐星角色面板。`BossArenaRules` 在 `ManualBattle` 内处理整队出击、死亡后冷却、单卡在场约束、真实炮击与Boss击杀胜利。`BossArenaController` 读取该模型绘制血条、卡牌和结算，不另做一份伤害或计时逻辑。

开发入口：`YesterdayConvoy.Editor.BossArenaTools.Author` 只创建缺失的资源／场景，随后校验并更新构建清单；`Evaluate` 使用真实 `ManualBattle` 自动部署就绪成员和施放就绪技能，输出本地 `artifacts/boss-arena/balance.json`。它比较已持有编队，不模拟招募概率，不代表玩家胜率。
