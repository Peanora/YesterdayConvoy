## 怎样打开

下载本分支或克隆后进入本目录，运行 `open-preview.cmd`，优先使用 Chrome，其次 Edge。也可把 `index.html` 拖入这两个浏览器。GitHub 文件页只显示源码，需先下载到本地打开。

无需安装 Unity、Node 或启动服务器。角色图片和源石图标均内嵌 HTML，可离线查看；复制 `index.html` 一个文件也能运行。窗口底部显示五个棋子，点击图片购买，右侧操作刷新、锁定与升级。

## 当前界面

- 只保留底部商店；去掉上方战场、车队招募标题和招募按钮。
- 使用 38 个已制作角色的真实立绘；默认展示源石虫、弩手、雪怪狙击手、游击队盾卫、爱国者。刷新可换出其他角色。
- 名字下方显示该角色携带的羁绊；不再显示动作说明或通用标签。
- 用人物背景的灰、绿、蓝、紫、金表示 1–5 费，取消左上数字角标与色条。
- 点击图片购买，购买后该格留空；锁定按钮使用开锁/闭锁图案。
- 货币统一为源石，余额、卡价、刷新和升级使用原游戏源石图标；按钮名为“升级”。

初始源石 32、等级 5、经验 8/20；刷新消耗 2、升级消耗 4 并增加 4 经验，满 20 升级。锁店期间刷新不消耗源石。这些数值和随机刷新仅供界面交互预览，不代表正式商店概率与最终平衡。

## 交付范围与来源

本目录是独立 HTML 交互预览，尚未接入 Unity 商店、编队、正式经济、升星或羁绊结算。购买只改变本页临时状态，重新打开即重置。没有修改 Assets、场景、Prefab、Packages 或 ProjectSettings，因此本目录不需要 Unity `.meta`。

角色图像来自工程角色快照 `7ec2860c398b692d73527c3533dd8affa40c1ecf`，原路径、角色费用和 PNG SHA256 见 [role-sources.json](role-sources.json)。M02–M10 使用待机图集首帧，浏览器按透明边界裁切；其他角色使用已有立绘。所有原 PNG 数据内嵌 HTML，不依赖作者本机路径。未上传已隐藏上方战场的旧概念背景或旧版预览。

羁绊以工程 `docs/MONSTER_BACKLOG.md` 和本轮讨论为依据，完整映射在 [synergies.json](synergies.json)。M07、M08、M17、M18、M22 的“战地拾荒”为讨论中的附加羁绊；本页只展示标签，没有赋予属性或结算效果。映射含 41 个设计条目，实际可刷新图像为 38 个；未制作角色不会进入刷新池。

源石原图取自 [PRTS 收录页面](https://prts.wiki/w/文件:图标_源石.png)，原 PNG 52×53，未重绘或修改像素；来源、下载链接和 SHA256 见 [originium-source.json](assets/originium-source.json)。PRTS 是社区资料站，不是权利人官方托管站。原游戏素材沿用工程来源记录，未取得新的公开再分发授权文件；此次按用户明确上传指令提交，不将作业用途或社区可下载性写成授权依据。未使用的另一张库存道具图未随预览提交。
