# 六星守军第四批：四个所选三技能样板

2026-10-28。按人类确认接入D21荒芜拉普兰德、D22余、D29塞雷娅、D30玛恩纳；第二、第三批本轮跳过，不删除原清单。当前共16名守军有独立技能试玩，剩余14名未接入。这里的“完整技能”指清单选定的第三技能，不代表一至三技能、所有天赋、模组与培养体系全部复刻。

## 试玩

启动EXE → **守军技能测试 · 含六星 → 六星第四批** → 选择人物 → 开始战斗。底部仍为玩家怪物，拖到红门部署；守军自动开技能。暂停可以部署，双方移动/技力/动作/冷却冻结；胜负可重开、返回选择。原12名、八人防线、双地图和40怪物入口保留。

每个测试用现有迷宫固定路线，不把四人强塞入旧八人地图。D21/D30配米格鲁作受伤/阻挡搭档；D22/D29另外配史都华德、炎熔，便于观察火墙法术与群体治疗。怪物临时提高生命和部署次数，提供塔露拉、源石虫、猎狗、酸液源石虫四卡；这些是测试数值，不覆盖正式关卡或其他角色配置。塔露拉火雨可用来完成试验，不改变其原有手动技力规则。

## 明确的适配与未做项

- 防守方技能由AI在满SP且有实际用途、现有动作播完后施放，原作手动技能不是玩家可操作的守方按钮。玛恩纳可能在未蓄满40秒时开技能；这是当前守军AI，不冒充原作强制满蓄力。
- 攻击/治疗范围采用现有XZ距离半径，非原作格点精确形状。余的全场火墙按施放时最近目标固定朝向，中心在身前0.5单位；跨墙判定看伤害来源和目标两侧。近战和全屏火雨不被当作可消弹弹道。
- 恐惧沿既有固定路线后退，不引入动态寻路。已发射的完整攻击/技能动作继续锁定移动，之后才后退；免控首领保留免控，暂停冻结。不是重新发明一条逃跑路线。
- 灼燃采用本作0.1量级试验：普通100/首领200阈值，爆发700真实生命伤害、法抗-20持续10秒，期间不重新积累。为适配现有生命规模，不声称1000/2000/7000原数值。
- 玛恩纳的卡西米尔联动是配置标签；本轮只有他本人启用，未为无关守军添加阵营。未接入三敌增伤/嘲讽反伤天赋。拉普兰德的20/40/60秒阶段天赋、额外第四浮游与沉默未纳入；塞雷娅的被动面板成长、所有人的模组/培养系统未纳入。
- 模型与动作采用此前已确认的原作默认预览，**没有新AI立绘或平移伪装行走**。四位均为站桩守军；玛恩纳没有原普通攻击，不制造该动作。塞雷娅背面没有起手/循环S3，使用原背面待机/治疗动作配合技能领域；其余实际有的正背面S3阶段接入。
- 追猎轮廓/领域/金色斩击为本项目程序特效；火墙还复用highwizard的CC0火焰动画。**不是原作整套外部特效、音效或原骨骼系统复刻**。原角色媒体非CC0、开放再分发权利未确认，来源记录继续保留。

## 文件与数据连接

`DefenderBatch4Tools.Apply`幂等建立4个独立试验与专用怪物配置，已有资产不覆盖人工值。`DefenderPlacement/DefenderSkillDefinition`只保存配置，生成不可变`DefenderSettings/DefenderSkillSettings`；生命、技力、浮游、墙朝向、元素积累、蓄力与计数独立存于每局状态。

`AdvancedDefenderSkills`作为`ManualBattle`的局部实现扩展统一模拟时钟，通过原`CombatShot/TryDamageUnit`及生命结算连接怪物护盾/法抗/复活等能力；真实伤害走既有生命损伤入口。`DefenderArt/DefenderRosterView`按相同动作窗口播放原生帧，`AdvancedDefenderView`仅读取战斗状态绘制特效，不制造额外伤害。`DefenderSkillTrials/DefenderBatch4Evidence`负责选择与独立Player验证。没有改主场景、Prefab、Packages、ProjectSettings。

运行资源位于`Assets/StreamingAssets/DefenderArt/D21{B}/D22{B}/D29{B}/D30{B}`：154PNG，168756309字节，另有8份运行清单和必要meta。原PNG字节保留，依正背面待机轮廓高度规范为1.25世界单位、统一脚底枢轴，不通过变形掩盖比例差异；全帧页哈希见[导入记录](art/DEFENDER-BATCH4-IMPORT.json)，原始URL和文件SHA见[来源记录](art/source-records/defender-batch4-approved.json)。不上传Spine源模型/工作区/缓存，不依赖作者本机路径加载。
