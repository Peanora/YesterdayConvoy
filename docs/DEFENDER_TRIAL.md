# 八人防线试玩

本轮目标：把已预览的8名守军放进一张可以实际交战的工业折线地图，检查造型、动作、地形和基础职业分工。不是八名角色的完整原作技能实现，也不是正式关卡或最终数值。

## 怎么玩

1. 启动本分支的 `Builds/Windows/YesterdayConvoy.exe`，或者在 Unity 打开 `Assets/_Game/Scenes/InitialDemo.unity` 后 Play。
2. 在初始选择页右上点击 **八人防线 · 折线工业地图**。原有单怪测试仍在原入口。
3. 拖动下方塔露拉卡牌到左下红门松手。20 DP、部署费2、最多4次、部署间隔2秒；参数仅供试玩。怪物沿浅色路线前进，合法目标在射程内时停步交战。
4. 空格暂停；暂停中可以拖动并立即部署，扣费后战斗仍暂停。技力、移动、攻击和治疗使用同一模拟时钟。
5. 技力满后点击场上塔露拉，再点旁边技能图标释放火雨。全图六波火雨也能用来检查不同高度守军的受击、治疗和死亡。
6. 只需一只怪物穿过右下蓝门即可获胜。失败、胜利都可重新开始；返回怪物选择会清理试验地图，并恢复原地图、红蓝门及镜头位置。

## 本轮角色

| 角色 | 地形 | 基础表现 | 尚未实现 |
| --- | --- | --- | --- |
| 米格鲁 | 地面 | 挡3、近战、独立高护甲 | 防御强化技能 |
| 斑点 | 地面 | 挡3；有伤员时治疗附近守军，否则攻击 | 有技力和持续时间的原作治疗模式 |
| 玫兰莎 | 地面 | 挡1、近战；攻击起手→挥砍→收手 | 攻击强化技能 |
| 克洛丝 | 高台 | 不阻挡、物理射击 | 二连射、天赋概率强化 |
| 史都华德 | 高台 | 不阻挡、法术单体攻击 | 强力击、高甲优先天赋 |
| 炎熔 | 高台 | 不阻挡、法术范围攻击 | 攻速技能 |
| 芙蓉 | 高台 | 只治疗受伤且存活的守军，优先生命比例最低者 | 治疗强化技能 |
| 梓兰 | 高台 | 不阻挡、法术单体攻击 | 停顿、主动攻速技能 |

法术使用项目已有伤害类型；当前进攻怪物未配置法抗，试验中按0法抗处理。治疗不复活、不超过最大生命；来源在前摇中死亡会取消尚未落地的效果。斑点的按伤员自动切换属于本轮基础适配，并非原作完整技能。

## 地图和后续调整

15×9模块工业检修场地，固定折返路线、三处地面阻挡点、分组高台、侧渠、后方风机与排水设施。继续使用原有已登记的工业材质和正向60°俯视轻透视；只在试验期间将镜头后移以容纳较大的场地，不修改镜头俯角、偏航或主场景。

关卡配置：`Assets/_Game/Data/Resources/DefenderTrial.asset`。每个守军的位置、生命、护甲、射程、攻击间隔与阻挡数在其中独立保存。塔露拉的本关参数保存在 `EightDefendersBattle.asset` / `EightDefendersCombat.asset`，不覆盖原塔露拉单怪关。

优先试玩：高台是否挡住后排、角色大小是否合适、血条是否重叠、路线是否一眼看懂、火雨是否过于容易清场。数值和平衡仍待人类试玩，完整商店、编队与八人技能不在本轮范围。

实际测试、构建与限制见 [QA](QA.md) 本轮记录；素材和关键连接见 [美术接入记录](art/DEFENDERS-FIRST8-INTEGRATION.md)。
