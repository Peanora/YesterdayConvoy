# 爱国者：V2特效接入与试玩

任务 [#62](https://github.com/Peanora/YesterdayConvoy/issues/62)，负责人霍利屹（shigaharuki17）。2026-11-05用户确认把已查看的V2接入游戏。基线main `8f4d604`，功能分支 `codex/patriot-native-vfx`。

## 怎样试玩

使用Unity **6000.6.5f1**，打开 `Assets/Scenes/MonsterTrial.unity` 并运行，在原有怪物选择菜单进入“爱国者”，拖动角色卡到红门。商店、战役等使用同一战斗控制器的入口也会自动显示爱国者特效。

普通单怪关的守军较弱，通常只能看到行军攻击，不能据此认定其他阶段不存在。复起仍需首次致命伤害；等待60秒后进入毁灭，前15秒有保护，之后才能再次受到致命伤害。投矛会在冷却满足后寻找最远的有效高台守军；没有高台目标时不会凭空投矛。

本机Windows构建在 `Builds/Windows/YesterdayConvoy.exe`，需保留整个Windows目录。构建对应源码与实际测试结果见该目录的 `BUILD-INFO.txt` 和 [QA](../QA.md)。首次打开源工程会生成可重建的角色缓存；运行图集和.meta已随源码提供，不依赖本机外部预览目录。

## 本次接入了什么

| 战斗阶段 | 画面 | 触发方式 |
| --- | --- | --- |
| 行军 | 出手残影、四次接触命中特效 | 同一普攻动作四个真实伤害事件 |
| 毁灭普攻 | 出手、打击、命中爆点 | 毁灭阶段普通攻击 |
| 投矛 | 蓄力、目标标记、上抛、落矛与爆点 | 实际投矛对象与弹道时钟 |
| 首次倒下 | 倒下、复起等待与起身爆发 | 首次致命伤害、60秒复起末段 |
| 灼烧 | 脉冲及范围表现 | 现有0.8秒伤害脉冲 |
| 最终死亡 | 原死亡效果 | 毁灭阶段真正死亡；保留死亡表现尾段 |

旧的爱国者线圈与通用子弹/命中圈由专属表现替代。其他角色的通用反馈和塔露拉火雨保持。暂停冻结动作与特效；重开或切换战斗清除残留。多名爱国者共享图集，帧通过各自属性块设置；空闲图集页会释放，避免把所有大图长期放在显存中。

## 与动作同步的时点

本次按用户已确认V2所使用的原始骨骼事件同步：行军在动作时间0.6333、0.7333、0.8333、0.9333秒命中；毁灭动作0.5333秒出手、0.72秒接触；投矛动作1.7秒出手、1.92秒命中。普通攻击动作与事件一起按实际攻速缩放，投矛仍使用自己的技能时钟。

四连击次数、各次伤害、攻击间隔、投矛伤害/目标规则、60秒复起和15秒保护未改变。本次修正的是旧版行军0.75秒起、每0.2秒一次、毁灭0.6833秒出手和投矛3秒出手的表现/事件时序。原作整段技能常见的约3秒蓄力，可能包含骨骼之外的前置调度；尚未逐帧核对原作整段实战，不能把这里的1.7秒称作原作完整技能规则。

## 素材与技术边界

19组效果来自原作原生粒子、材质和纹理，先在独立Unity工程用原着色器离线生成动画，再在游戏播放跨显卡图集。原着色器在本机Vulkan可用、默认Direct3D不支持，因此不直接把Android原包塞进游戏，也不修改显卡、包或项目设置。

图集保留加色光与半透明遮挡的混合关系，采用独立Shader；较大效果使用512像素单帧，其余256，30fps。图集是固定视角的二维表现，挂点、缩放、地面适配与组合是本作适配，不是原作三维粒子或完整战斗脚本的逐像素移植。本次没有接入音效。

原始来源、文件哈希、处理方法和真实权利状态见 [独立来源记录](../art/source-records/patriot-v2-native.json)。用户要求配套运行素材随源码上传；第三方原作资源仍未附可核对的公开再分发授权，不标为CC0或自有版权。原包、提取缓存和预览视频不属于运行依赖，本轮不提交。

## 如何复核全部阶段

GPU测试为 `PatriotPresentationTests`：先从真实MonsterTrial菜单进入并自然命中，再使用明确标注的开发夹具覆盖复起、毁灭、投矛、灼烧、死亡、暂停及清理。夹具通过真实伤害接口触发阶段，不能把夹具画面称作普通关自然通关。

Windows Development构建可运行：

```powershell
.\YesterdayConvoy.exe -patriotVfxSmokeTest -demoEvidenceDir D:\游戏开发\YesterdayConvoy-Latest\artifacts\patriot-player -logFile D:\游戏开发\YesterdayConvoy-Latest\artifacts\patriot-player.log
```

该参数仅用于显式开发验证，结束后退出；普通启动不运行夹具。成功时生成 `patriot-runtime-check.json` 与8张实际相机截图，日志包含 `PATRIOT_VFX_CHECK_PASS`。不要把仅有Renderer数量、编译或仓库Actions通过当作画面验证。
